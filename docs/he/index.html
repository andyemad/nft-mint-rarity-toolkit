02התקנת Hermes

Hermes הוא הסוכן. אתה מדביק שורה אחת בחלון טרמינל והוא מתקין את עצמו. זה הדבר הכי טכני בכל המדריך הזה.

Windows

פתח את תפריט Start, הקלד PowerShell, פתח אותו והדבק את זה:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Mac

לחץ Command + Space, הקלד Terminal, לחץ Enter והדבק:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Linux

פתח את הטרמינל שלך והדבק:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
הוא מוריד לבד את כל מה שהוא צריך וזה לוקח כמה דקות. תן לטקסט לרוץ, אתה לא צריך לקרוא אותו.

בדוק שזה עבד

סגור את החלון, פתח חלון חדש והקלד:

hermes doctor

זה מדפיס רשימת בדיקות. ירוק זה בסדר. אם משהו חסר, הוא אומר לך את הפקודה המדויקת לתקן.

תן לו מוח

הסוכן צריך מודל שיחשוב איתו, וזה המנוי ב-$10. נרשמים כאן: opencode.ai.

ואז הוסף את המפתח שהוא נותן לך לקובץ ההגדרות.

Windows 
notepad $env:USERPROFILE\.hermes\.env

הוסף את השורה הזו בסוף, במקום YOUR_KEY_HERE עם המפתח שלך, ואז שמור וסגור:

OPENCODE_GO_API_KEY=YOUR_KEY_HERE
Mac ו-Linux 
printf 'OPENCODE_GO_API_KEY=%s\n' 'YOUR_KEY_HERE' >> ~/.hermes/.env

עכשיו תגיד לו להשתמש במנוי ותגיד שלום:

hermes model
hermes chat -q "hello, what model are you?"

אם הוא עונה, הסוכן עובד. כל מה שאחרי זה זה רק להוסיף לו דברים.

03הגדרת Discord או Telegram

זה החלק שהופך אותו לשימושי. אחרי זה אתה כבר לא צריך את הטרמינל. רק שולח לו הודעה.

בחר את האפליקציה שאתה כבר משתמש בה. שתיהן לוקחות כמה דקות ועובדות אותו דבר אחר כך.

Discord

Discord משנה מדי פעם את התפריטים שלו, אז אם כפתור זז, חפש את הדומה ביותר.

  1. היכנס ל- discord.com/developers/applications ולחץ על New Application. תן לו כל שם.
  2. בתפריט השמאלי לחץ על Bot. גלול אל Privileged Gateway Intents והעבר את Message Content Intent ל- ON. זו הקריטית מכולן: אם תדלג עליה, הבוט שלך ייראה לגמרי שבור.
  3. עדיין באותו עמוד, לחץ על Reset Token והעתק את מה שמופיע. הוא מוצג פעם אחת בלבד. תתייחס אליו כמו לסיסמה.
  4. בתפריט השמאלי לחץ על Installation. הפעל Guild Install, וודא שה-Scopes כוללים את bot ו- applications.commands. העתק את קישור ההתקנה שהוא מציג לך.
  5. פתח את הקישור בדפדפן והוסף את הבוט לשרת שלך. אתה צריך להיות הבעלים או המנהל של השרת הזה.
  6. מצא את מזהה המשתמש שלך. ב-Discord היכנס ל- Settings → Advanced, הפעל Developer Mode, ואז לחץ ימני על השם שלך ובחר Copy User ID. זה מספר ארוך.
  7. הרץ את ההגדרה והדבק את הטוקן ואת מזהה המשתמש:
hermes gateway setup

בחר Discord כשהוא שואל. ואז הפעל ובדוק:

hermes gateway run

השאר את החלון פתוח ושלח לבוט הודעה פרטית ב-Discord. הוא אמור לענות. אחרי שהוא עונה, לחץ Ctrl + C כדי לעצור אותו, והרץ את שתי השורות האלה כדי שהוא יעלה לבד מכאן והלאה: 

hermes gateway install
hermes gateway start
בהודעות פרטיות הוא עונה להכול. בערוץ בשרת הוא עונה רק כשמתייגים אותו, כך שהוא אף פעם לא מציף את החברים שלך.
אם הוא אף פעם לא עונה, זה כמעט תמיד אחד משני דברים: Message Content Intent עדיין כבוי, או שמזהה המשתמש הועתק לא נכון. חזור על שלבים 2 ו-6.

Telegram

Telegram היא הדרך המהירה. Hermes יוצר את הבוט בשבילך: סורקים קוד עם הטלפון ולוחצים על כפתור אחד.

  1. הרץ את ההגדרה:
hermes gateway setup
  1. בחר Telegram כשהוא שואל, ואז בחר Automatic. קוד מרובע מופיע בחלון, עם קישור מתחתיו.
  2. כוון את מצלמת הטלפון אל הקוד, או פתח את הקישור. Telegram נפתחת ומבקשת שתאשר. לחץ על Create Bot. אפשר לשנות את השם שלו קודם אם בא לך.
  3. חזרה בחלון, הוא אומר שהוא זיהה את חשבון ה-Telegram שלך ושואל אם לאשר אותו. תגיד כן, וכן לכמה השאלות שאחרי זה. רק אתה יכול לדבר עם הבוט.

ואז הפעל ובדוק:

hermes gateway run

השאר את החלון פתוח, מצא את הבוט החדש שלך ב-Telegram ושלח לו הודעה. הוא אמור לענות. אחרי שהוא עונה, לחץ Ctrl + C כדי לעצור אותו, והרץ את שתי השורות האלה כדי שהוא יעלה לבד מכאן והלאה: 

hermes gateway install
hermes gateway start
מעדיף ליצור את הבוט בעצמך? ב-Telegram, שלח הודעה ל- @BotFather, שלח /newbot, וענה על שתי השאלות שלו. שם המשתמש חייב להסתיים ב- bot. הוא נותן לך טוקן: מוצג פעם אחת, תתייחס אליו כמו לסיסמה. ואז שלח הודעה ל- @userinfobot כדי לקבל את מזהה המשתמש שלך, שהוא מספר. בחר Manual בהגדרה והדבק את שניהם.
בצ'אט פרטי הוא עונה להכול. בקבוצה הוא עונה רק כשמתייגים אותו או מגיבים לו, כך שהוא אף פעם לא מציף את החברים שלך. כל פרומפט בהמשך המדריך עובד אותו דבר כאן.
אם הוא עונה בקוד צימוד במקום תשובה, הוא עדיין לא מכיר את החשבון שלך. הרץ hermes pairing approve telegram <code> בטרמינל ושלח לו הודעה שוב.

04הורדת הסקילים

שלוש שורות. זה מוריד את הסקילים ומתקין אותם בסוכן שלך:

git clone https://github.com/andyemad/nft-mint-rarity-toolkit.git
cd nft-mint-rarity-toolkit
./install.sh

אפשר לבדוק אותם בכל רגע עם hermes skills list. הרצה חוזרת של המתקין בהמשך היא בטוחה, היא לא תשבור כלום.

אין git מותקן, או שאתה לא בטוח? הורד את קובץ ה-ZIP מ- הקישור הזה, חלץ אותו, פתח טרמינל בתוך התיקייה הזו והרץ bash install.sh.

דבר אחרון, שלושה עזרים קטנים שסקילי הארנקים והמסחר צריכים:

pip install eth-account coincurve pycryptodome

06למנט Hashcats (ודרופים דומים)

לחלק מהדרופים אין מחיר. במקום לשלם, אתה צריך למצוא מספר מזל, ומי שמוצא אותו ראשון מקבל את החתול. לזה מתכוונים כשהם אומרים שהמינט נפתר ולא נקנה.

הלפטופ שלך יכול לעשות את זה, אבל זה ייקח ימים, ואנשים עם מחשבים שכורים וחזקים מוצאים אותם בדקות. אז שוכרים מחשב לכמה דקות. זו הסיבה היחידה לכל העסק הזה.

שוכרים מחשב לכמה דקות (חינם להתחלה)

Modal שוכר מחשבים לפי שנייה. אתה לא קונה כלום. נרשמים וזה מגיע עם $30 של מחשוב חינם בכל חודש, שזה בערך שבע שעות במכונות המהירות שלהם, בערך $4 לשעה. לניסיונות מזדמנים סביר שלעולם לא תשלם כלום.

  1. נרשמים בחינם ב- modal.com. ה-$30 כבר כלולים.
  2. ואז הרץ את שתי הפקודות האלה פעם אחת:
pip install modal
modal setup

השנייה פותחת דפדפן ומקשרת את החשבון שלך. זה כל מה שצריך.

מה להקליד ב-Discord

זו כל הפעולה. תייג את הבוט שלך והדבק את זה:

@yourbot תשתמש בסקיל pow-mint-mining על hashcats. תראה לי את הסיבוב הנוכחי ותכין הכל, אבל אל תוציא כלום עדיין

הוא מדווח לך בחזרה על הסבב. כשאתה באמת רוצה ללכת על זה:

@yourbot קדימה תכרה את הסיבוב הנוכחי. תעצור כשתמצא אחד, או אחרי 15 דקות

וכדי לראות איך זה הלך:

@yourbot הצלחנו להשיג אחד? תראה לי את העסקה

מה הוא עושה בשבילך

  • הוא בודק קודם את כל ההתקנה, כך שריצה אף פעם לא מתחילה שבורה
  • הוא עושה את החיפוש על המחשב השכור, לא על שלך
  • הוא בודק כל תשובה לפני שהוא מוציא משהו, כך שתשובה שהגיעה מאוחר מדי לא תעלה לך עמלה
  • הוא שולח את העסקה מהארנק שלך ונותן לך את הקישור

שני הדברים שרק אתה יכול לעשות

  • שים קצת ETH בארנק. גם ניצחון עולה כמה סנטים בעמלות. שום דבר לא יכול לעשות את החלק הזה בשבילך.
  • תשמור על ניסיונות קצרים. הסבבים מתחלפים כל הזמן, ועבודה שנעשתה לסבב שכבר נגמר היא מבוזבזת. קצר ותכוף עדיף על ריצה ארוכה אחת.
תהיה כן לגבי הסיכויים. אתה מתחרה עם כל מי שמנסה את אותו דרופ, ואתה משלם על המחשוב בין אם תנצח ובין אם תפסיד. בשביל זה יש את הקרדיט החינם. תשתמש בו, תשמור על ניסיונות קצרים, ואל תטען עוד כסף בציפייה לחתול מובטח.

עוד דרופים שזה עובד עליהם

אותו רעיון ואותו סוג של פרומפט. רק מזכירים את זה שאתה רוצה במקום: 

@yourbot תשתמש בסקיל pow-mint-mining על FAB4200 ותגיד לי כמה זה יעלה לי

07דברים לבקש ממנו

אין ניסוח מיוחד. הדבק קישור ותגיד מה אתה רוצה. קישור ל-OpenSea, ציוץ, אתר מינט, כתובת ארנק, כתובת חוזה. אם הוא לא מבין למה אתה מתכוון, הוא שואל אותך.

הדבק קישור של OpenSea

@yourbot דרג את כל הקולקציה הזו לפי נדירות ותראה לי את 20 המובילים
@yourbot אילו מהיקרים כאן רשומים בזול כרגע?
@yourbot מה מחיר הרצפה של זה והוא עולה או יורד?
@yourbot הארנקים שמינטו את זה הם אנשים אמיתיים או בוטים?
@yourbot שווה לקנות את זה במחיר הרצפה הנוכחי?
@yourbot כמה אנשים מחזיקים את זה, וכמה זה מרוכז?

הדבק ציוץ שכתוב בו "למנט את זה"

זה השימושי. תדביק את הציוץ והוא מבין מה המינט, כמה הוא באמת עולה, אם הוא עוד פתוח, ואם הפרויקט נראה אמיתי — לפני שמשהו נוגע בארנק שלך. 

@yourbot <tweet link> תמינט את זה
@yourbot <tweet link> מה המינט הזה והוא אמיתי?
@yourbot <tweet link> אני יכול למנט את זה בחינם?
@yourbot <tweet link> כמה יעלה לי בפועל למנט 3 כאלה?
@yourbot <tweet link> זה החוזה האמיתי או העתקה?
@yourbot <tweet link> תגדיר התראה למתי שזה עולה לאוויר
הוא לא סתם יורה עסקה. הוא קורא את הציוץ, מוצא את החוזה, בודק את המחיר ואת ההיצע אונצ'יין, מראה לך מה הוא מצא, ומחכה שתגיד קדימה.

הדבק אתר מינט, או סתם כתובת חוזה

@yourbot מה החוזה הזה בעצם עושה? <address>

הדבק כתובת ארנק

@yourbot הארנק הזה נראה כמו בוט או כמו אדם?

בקש ממנו לעקוב אחרי משהו בשבילך

@yourbot תזכיר לי כשהמינט הזה נפתח בעוד שעה

בקש ממנו לקנות או למנט בשבילך

כל אחד מאלה בודק קודם ואומר לך את העלות לפני שהוא עושה משהו. שום דבר לא עובר עד שאתה אומר קדימה.

בקש ממנו להסביר משהו

@yourbot תסביר מה זה מינט proof of work, במילים פשוטות

@yourbot מה זה אומר "revealed" כאן?

הכלל הכללי: אם אתה יכול להדביק את זה, כנראה שהוא יכול להסתכל על זה. קישורים, צילומי מסך, כתובות, ציוצים, גיליונות. אם אתה לא בטוח איך לבקש, פשוט תאר מה אתה מנסה לעשות ותן לו להבין את השאר.
רוצה לשנות איך סקיל עצמו עובד? זה עמוד נפרד, כי זה הדבר הכי שימושי שתוכל ללמוד כאן: לשפר את הסקילים פשוט בדיבור.

08הגדרת Vercel

Vercel מעלה אתר או עמוד לאינטרנט בחינם. אתה לא צריך אותו כדי להריץ את הסוכן. אתה צריך אותו אם בא לך עמוד ציבורי משלך: קישור שאפשר לשתף, תיק עבודות, עמוד תיעוד, המדריך הזה.

פתח חשבון

נרשמים ב- vercel.com/signup עם GitHub, Google או אימייל. החבילה החינמית מספיקה לכל מה שכאן.

הדרך הקלה: לחבר פרויקט GitHub

  1. ב-Vercel לחץ על Add New → Project.
  2. חבר את חשבון ה-GitHub שלך ובחר את הריפו שתרצה להעלות.
  3. אם קבצי האתר שלך יושבים בתיקייה ולא בשורש, הגדר Root Directory לתיקייה הזו. בשביל העמוד של המדריך הזה התיקייה היא docs.
  4. לחץ על Deploy. דקה אחר כך יש לך קישור חי.

מכאן והלאה, בכל פעם שאתה דוחף ל-GitHub, Vercel בונה את האתר מחדש לבד. זה כל התהליך.

הדרך עם הטרמינל

אם אתה מעדיף לפרוס ישר מהמחשב שלך:

npm install -g vercel
vercel login

# then, from inside the folder you want online
vercel --prod

הוא שואל כמה שאלות בפעם הראשונה ואז מדפיס את הקישור החי שלך.

פרס את העמוד של המדריך הזה כניסיון

git clone https://github.com/andyemad/nft-mint-rarity-toolkit.git
cd nft-mint-rarity-toolkit
npx vercel deploy docs --prod

דומיין משלך

אופציונלי. בהגדרות Settings → Domains של הפרויקט אפשר להוסיף דומיין בבעלותך, או להסתפק בכתובת החינמית your-project.vercel.app שהוא נותן לך.

מה Vercel לא יכולה לעשות: להריץ את הסוכן שלך. Vercel מגישה רק אתרים שנטענים לפי דרישה. הסוכן שלך הוא תוכנית שצריכה להישאר דלוקה, אז היא גרה במחשב שלך או בשרת. אם אי פעם תראה פריסה שנכשלת עם שגיאת 402 — החשבון הזה עבר את מכסת ההעברות של החבילה החינמית. פתח פרויקט חדש, או השתמש ב-GitHub Pages או Cloudflare Pages, שמגישים את אותם קבצים.

09המחשב שלך, שרת, או אחסון מנוהל?

שניהם עובדים. ההבדל האמיתי היחיד הוא מה קורה כשאתה סוגר את הלפטופ.

חינם

על המחשב שלך

  • אין מה להגדיר מעבר להתקנה שכבר עשית
  • מהירות מלאה, והוא יכול להשתמש במה שיש רק לך: הדפדפן, הקבצים, הארנקים
  • נעצר כשאתה סוגר את המכסה או שם אותו לישון
  • כל משימה מתוזמנת, התראה או מעקב לילה מפספסים את החלון שלהם
  • מתאים ל: ניסויים, שימוש בשעות היום, כל דבר שאתה בעצמך עוקב אחריו
~$5 / לחודש

על שרת קטן

  • אף פעם לא ישן. הופעל פעם אחת, הוא נשאר למעלה
  • מעקבים, התראות ומשימות מתוזמנות באמת רצים ב-4 לפנות בוקר
  • אתה מגיע אליו מהטלפון דרך Discord מכל מקום
  • אין מסך, אז אתה לא רואה אותו עובד חוץ מאשר בצ'אט
  • מתאים ל: משימות מתוזמנות, מעקבי לילה, כל דבר שאתה רוצה שיעבוד כל הזמן
מחיר בפורטל

או לתת ל-Nous לארח אותו

  • Hermes Cloud מריץ את המופע בשבילך
  • אין שרת להגדיר, לעדכן או להפעיל מחדש בעצמך
  • להפעיל, לעצור ולהפעיל מחדש מדף אינטרנט, או לבקש מהסוכן שלך
  • אותה הגדרת Discord כמו בכל מקום אחר
  • מתאים ל: מי שלא רוצה להריץ שרת בכלל

או לתת ל-Nous לארח אותו בשבילך

אם להריץ שרת נשמע כמו עבודה שאתה לא רוצה, Nous Research מארחת מופעי Hermes Cloud. אתה מקבל סוכן שתמיד עובד, בלי לבחור ספק, לאבטח שרת או לדאוג לעדכונים.

  1. פתח Nous Portal חשבון ב- portal.nousresearch.com.
  2. היכנס ל- Agents צור מופע. תן לו שם.
  3. חבר אליו Discord או Telegram בדיוק כמו בשלב 03. אותן פקודות, רק על המופע.

מכאן והלאה אתה מנהל אותו מהדף הזה. להפעיל, לעצור, להפעיל מחדש או למחוק — הכול שם. המחירים מופיעים בפורטל לצד החבילות.

מנוי אחד יכול לכסות את שני התפקידים. חבילה בפורטל יכולה גם להיות המוח של הסוכן במקום מנוי מודל נפרד: היא כוללת קטלוג גדול של מודלים, ובנוסף חיפוש אינטרנט, יצירת תמונות וקול בניהול מלא — הכול דרך התחברות אחת. הרץ hermes setup --portal והוא מתחבר לבד. אם אתה כבר משלם על OpenCode, אתה לא צריך את שניהם.
כבר מריץ סוכן מקומית? אתה יכול לנהל את מופעי הענן שלך פשוט בלבקש ממנו, במקום ללחוץ בכל האתר. פקודה אחת מחברת את הסוכן המקומי שלך לפורטל: 
hermes mcp add --url https://portal.nousresearch.com/mcp --auth oauth hermes-cloud

אחרי זה אתה יכול להגיד "תציג את סוכני הענן שלי", "כמה המופע הזה עולה לי", או "תפעיל מחדש את זה שעצור".

לעבור לשרת

  1. קח אחד מ-Hetzner או DigitalOcean, בערך $5 לחודש. בחר Ubuntu כמערכת ההפעלה. האפשרות הקטנה ביותר מספיקה.
  2. בצע את אותה שורת התקנה של Linux משלב 02 על השרת הזה במקום על המחשב שלך.
  3. חזור על שלבי ה-Discord והסקילים שם. אלה אותן שלוש פקודות.
  4. אתה יכול להריץ את שניהם. המחשב והשרת הם סוכנים נפרדים, וכל אחד מקבל טוקן בוט Discord משלו אם תרצה.
