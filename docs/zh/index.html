先从前三项开始。Vercel 和服务器后面才用得上，而且两个都可以跳过。

02配置 Hermes

Hermes 就是那个智能体。把一行命令粘进终端窗口，它就会自己装好。这是整份指南里技术含量最高的一步。

Windows

打开开始菜单，输入 PowerShell，打开它，然后粘贴下面的内容：

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Mac

按 Command + Space，输入 Terminal，按回车，然后粘贴：

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Linux

打开终端并粘贴：

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
它会自己下载所需的全部内容，整个过程要几分钟。让屏幕上的文字滚过去就好，不用逐行去读。

检查是否装好

关掉窗口，重新开一个，然后输入：

hermes doctor

它会打印一份检查清单。绿色表示没问题。如果缺了什么，它会直接给出修复用的确切命令。

给它装上大脑

智能体需要一个模型来思考，也就是那份 $10 的订阅。在这里注册： opencode.ai.

然后把它给你的密钥填进设置文件。

Windows 
notepad $env:USERPROFILE\.hermes\.env

在文件末尾加上这一行，把 YOUR_KEY_HERE 换成你自己的密钥，然后保存并关闭：

OPENCODE_GO_API_KEY=YOUR_KEY_HERE
Mac 和 Linux 
printf 'OPENCODE_GO_API_KEY=%s\n' 'YOUR_KEY_HERE' >> ~/.hermes/.env

现在让它使用这份订阅，并向它打个招呼：

hermes model
hermes chat -q "hello, what model are you?"

它要是回话了，说明智能体已经能跑。后面的事都是往它身上加东西。

03配置 Discord

这一步才让它变得好用。做完之后你再也不用碰终端，直接给它发消息就行。

Discord 时不时会调整菜单，如果按钮位置变了，就找最接近的那个。

  1. 打开 discord.com/developers/applications ，点击 New Application。名字随便起。
  2. 在左侧菜单点击 Bot。向下滚动到 Privileged Gateway Intents ，把 Message Content Intent 切换为 ON。这一项最关键：漏掉它，你的机器人看起来就像彻底坏掉了。
  3. 还是在这个页面，点击 Reset Token ，把出现的内容复制下来。它只显示一次，请当作密码一样对待。
  4. 在左侧菜单点击 Installation。打开 Guild Install，并确认 scopes 里包含 bot 和 applications.commands。复制它显示给你的安装链接。
  5. 在浏览器里打开这个链接，把机器人添加到你的服务器。你需要是该服务器的所有者或管理员。
  6. 找到你自己的用户 ID。在 Discord 里进入 Settings → Advanced，打开 Developer Mode，然后右键点自己的名字，选择 Copy User ID。它是一串很长的数字。
  7. 运行配置命令，把 token 和用户 ID 粘进去：
hermes gateway setup

问到时选 Discord。然后启动并测试：

hermes gateway run

让那个窗口开着，在 Discord 里给机器人发一条私信，它应该会回复。等它回了，按 Ctrl + C 把它停掉，再运行下面两行，让它以后自动启动： 

hermes gateway install
hermes gateway start
在私信里 它什么都会回。 在服务器频道里 它只在被 @ 时才回复，所以不会刷屏骚扰你的朋友。
如果它一直不回复，几乎总是两个原因之一：Message Content Intent 还关着，或者用户 ID 复制错了。把第 2 步和第 6 步重做一遍。

04下载技能

三行命令。它会下载技能并安装进你的智能体：

git clone https://github.com/andyemad/nft-mint-rarity-toolkit.git
cd nft-mint-rarity-toolkit
./install.sh

随时可以用下面的命令检查 hermes skills list。以后重跑一遍安装器也没问题，不会弄坏任何东西。

没装 git，或者不确定？ 从 这个链接下载 ZIP 压缩包，解压后在该文件夹里打开终端并运行 bash install.sh.

最后一件事：三个小工具，钱包和交易类技能会用到：

pip install eth-account coincurve pycryptodome

06铸造 Hashcats（以及类似的发售）

有些发售没有标价。你不用付钱，而是要找出一个幸运数字，谁先找到谁就能拿到这只猫。这就是人们说的“铸造不是买来的，而是算出来的”。

你的笔记本也算得动，但要花上好几天，而租了大机器的人几分钟就能找到。所以你只需租几分钟算力。这也是唯一需要这么做的理由。

租几分钟算力（起步免费）

Modal 按秒出租算力。你什么都不用买。注册之后，它就自带 每月 $30 的免费算力，按大约每小时 $4 算，相当于七个小时的高性能机器时间。只是偶尔试几次的话，你大概率一分钱都不用花。

  1. 在 modal.com免费注册，$30 已经包含在内。
  2. 然后运行下面两条命令，只需一次：
pip install modal
modal setup

第二条会打开浏览器并关联你的账号。配置到此为止。

在 Discord 里输入什么

整个操作就这么点。@ 一下你的机器人，粘贴下面这句：

@yourbot 用 pow-mint-mining 技能挖 hashcats。先给我看当前轮次，把一切都准备好，但先别花任何钱

它会把这轮的情况回报给你。真想下手的时候，用这条：

@yourbot 开始挖当前这一轮。挖到就停，或者 15 分钟后停

想看结果如何：

@yourbot 挖到了吗？把交易给我看

它替你处理的事

  • 先检查整套配置，避免一上手就是坏的
  • 搜索跑在租来的机器上，不占用你自己的电脑
  • 花钱之前会校验每个结果，来晚了的答案不会让你白付手续费
  • 用你的钱包发交易，并把链接给你

只有你能做的两件事

  • 往钱包里放一点 ETH。 就算赢了也要付几美分的手续费，这一步谁也替不了你。
  • 每次尝试别拖太久。 轮次一直在往前走，为一个已经结束的轮次算出来的结果都是白费。短而频繁，胜过一次性长跑。
对胜率要有清醒认识。 你在和所有盯上同一场发售的人赛跑，而且不管输赢算力费都得付——免费额度就是干这个用的。把它用掉，每次尝试压短一点，也别充钱进去指望必得一只猫。

同样适用的其他发售

思路和话术都一样，只要换成你想要的那一个： 

@yourbot 用 pow-mint-mining 技能挖 FAB4200，告诉我大概要花我多少钱

07可以问它什么

没有什么特殊说法。 粘贴一个链接，说清楚你想要什么。 OpenSea 链接、一条推文、铸造网站、钱包地址、合约地址都行。要是它看不明白你的意思，它会直接问你。

粘贴一个 OpenSea 链接

@yourbot 这里面哪些稀有的现在挂得很便宜？
@yourbot 这个的地板价是多少？在涨还是在跌？
@yourbot 铸造这个的钱包是真人还是机器人？
@yourbot 以现在的地板价，值得买吗？
@yourbot 有多少人持有？集中度高不高？

粘贴一条写着“来铸这个”的推文

这条最实用。把推文丢给它，它就会查清这是什么铸造、真实花费多少、是否还在开放、项目看着靠不靠得住——这一切都发生在碰你钱包之前。 

@yourbot <tweet link> 把这个铸了
@yourbot <tweet link> 这是什么铸造？是真的吗？
@yourbot <tweet link> 这个能免费铸造吗？
@yourbot <tweet link> 铸 3 个实际要花我多少钱？
@yourbot <tweet link> 这是真合约还是仿的？
@yourbot <tweet link> 它一上线就提醒我
它不会上来就发交易。它会读推文、找到合约、上链核对价格和供应量，把查到的东西摆给你看，然后等你点头。

让它替你买或铸造

以上每一种都会先做检查，动手前先告诉你花费。你点头之前，什么都不会真的执行。 

@yourbot 帮我铸 1 个，先给我看费用，等我点头再动

@yourbot 没有我同意，不要花任何钱

08配置 Vercel

Vercel 可以免费把网站或页面放到线上。运行智能体并不需要它。你只有想要一个自己的公开页面时才需要：一个能分享的链接、作品集、文档页，或者这份指南。

注册账号

在 vercel.com/signup 用 GitHub、Google 或邮箱注册。免费套餐足够应付这里的一切。

省事的做法：关联 GitHub 项目

  1. 在 Vercel 里点击 Add New → Project.
  2. 连上你的 GitHub 账号，选择想上线的仓库。
  3. 如果你的网页文件不在仓库根目录而在某个文件夹里，就把 Root Directory 设为那个文件夹。本指南的页面用的是这个文件夹： docs.
  4. 点击 Deploy。一分钟后你就有一个可访问的链接了。

之后每次推送到 GitHub，Vercel 都会自动重新构建站点。整个流程就这么简单。

用终端的做法

如果你更想直接从自己电脑上部署：

npm install -g vercel
vercel login

# then, from inside the folder you want online
vercel --prod

第一次它会问你几个问题，然后打印出你的线上链接。

把本指南的页面部署上去试一遍

git clone https://github.com/andyemad/nft-mint-rarity-toolkit.git
cd nft-mint-rarity-toolkit
npx vercel deploy docs --prod

你自己的域名

可选。在项目的 Settings → Domains 里可以添加你自己拥有的域名，也可以直接用免费的 your-project.vercel.app 它分配给你的地址。

Vercel 做不到的事： 运行你的智能体。Vercel 只托管按需加载的网站，而你的智能体是必须一直开着的程序，所以它只能待在你的电脑或服务器上。如果你看到部署失败并报了 402 错误，说明那个账号已经超出了免费套餐的流量额度。新建一个项目，或者改用 GitHub Pages、Cloudflare Pages，它们能提供同样的文件。

09自己的电脑、服务器，还是托管？

两种都行。真正的区别只在合上笔记本之后会发生什么。

免费

放在自己的电脑上

  • 除了已经做过的安装，不用再配置任何东西
  • 全速运行，还能用只有你才有的东西：你的浏览器、你的文件、你的钱包
  • 合上盖子就会停 或者让它进入睡眠
  • 所有定时任务、提醒或整夜盯盘都会错过时间窗口
  • 适合：试水、白天使用、你自己盯着的事情
约 $5 / 月

放在一台小服务器上

  • 从不休眠。启动一次就一直在线
  • 盯盘、提醒和定时任务在凌晨 4 点也照常触发
  • 在任何地方都能用手机上的 Discord 找到它
  • 没有屏幕，除了聊天看不到它在干什么
  • 适合：定时任务、整夜监控、任何需要一直跑着的事
价格见 Portal

或者让 Nous 帮你托管

  • Hermes Cloud 替你运行这台实例
  • 不用自己配置、打补丁或重启服务器
  • 在网页上就能启动、停止、重启，也可以直接让你的智能体去做
  • Discord 的配置方式和其他方案完全一样
  • 适合：完全不想自己运维服务器的人

或者让 Nous 替你托管

如果运维服务器听起来正是你不想要的麻烦， Nous Research 提供 Hermes Cloud 实例托管。你会得到一个永远在线的智能体，不用挑服务商、不用加固服务器，也不用操心更新。

  1. 注册一个 Nous Portal 账号，网址是 portal.nousresearch.com.
  2. 打开 Agents 页面，创建一个实例，给它起个名字。
  3. 按照第 03 步的做法把 Discord 接上去，命令完全一样，只是要在实例上运行。

之后你就在那个网页上管理它：启动、停止、重启、删除都在那里。价格和套餐一起列在 Portal 上。

一份订阅就能同时顶这两个角色。 Portal 套餐也能直接当智能体的大脑，不必另买模型订阅：它包含一个庞大的模型库，还附带托管的网页搜索、图像生成和语音，一个登录就能全部搞定。运行 hermes setup --portal 它就会自动接好。如果你已经在为 OpenCode 付费，就不必两样都买。
本地已经在跑智能体了？ 你可以直接叫它去管理云实例，不用在网站上到处点。一条命令就能把本地智能体连到 Portal： 
hermes mcp add --url https://portal.nousresearch.com/mcp --auth oauth hermes-cloud

之后你就可以说“列出我的云端智能体”“那台实例花了我多少钱”，或者“把停掉的那台重启”。

搬到服务器上

  1. 去 Hetzner 或 DigitalOcean 买一台，大约 $5/月。系统选 Ubuntu 。最小的配置就完全够用。
  2. 把第 02 步里 Linux 的那行安装命令拿到服务器上执行，而不是在你自己的电脑上。
  3. 在那台服务器上重复 Discord 和技能的步骤，同样是那三条命令。
  4. 两边可以同时跑。你的电脑和服务器是两个独立的智能体，需要的话各自用各自的 Discord 机器人 token。
比较稳妥的做法： 今天先在自己电脑上跑起来，等你真有想让它整夜运行的活儿，再去租服务器。
