02Installer Hermes

Hermes, c’est l’agent. Vous collez une seule ligne dans une fenêtre de terminal et il s’installe tout seul. C’est la chose la plus technique de tout ce guide.

Windows

Ouvrez le menu Démarrer, tapez PowerShell, ouvrez-le et collez ceci :

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Mac

Appuyez sur Commande + Espace, tapez Terminal, appuyez sur Entrée et collez :

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Linux

Ouvrez votre terminal et collez :

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
Il télécharge tout seul tout ce dont il a besoin, ça prend quelques minutes. Laissez le texte défiler, vous n’avez pas besoin de le lire.

Vérifiez que ça a marché

Fermez la fenêtre, ouvrez-en une nouvelle et tapez :

hermes doctor

Cela affiche une liste de vérification. Le vert veut dire que tout va bien. S’il manque quelque chose, il vous indique la commande exacte pour le corriger.

Donnez-lui un cerveau

L’agent a besoin d’un modèle pour réfléchir, et c’est l’abonnement à $10. Inscrivez-vous ici : opencode.ai.

Ajoutez ensuite la clé qu’il vous donne dans le fichier de configuration.

Windows 
notepad $env:USERPROFILE\.hermes\.env

Ajoutez cette ligne à la fin, en remplaçant YOUR_KEY_HERE par votre clé, puis enregistrez et fermez :

OPENCODE_GO_API_KEY=YOUR_KEY_HERE
Mac et Linux 
printf 'OPENCODE_GO_API_KEY=%s\n' 'YOUR_KEY_HERE' >> ~/.hermes/.env

Dites-lui maintenant d’utiliser l’abonnement et dites-lui bonjour :

hermes model
hermes chat -q "hello, what model are you?"

S’il répond, l’agent fonctionne. Tout ce qui suit consiste à lui ajouter des choses.

03Configurer Discord

C’est l’étape qui le rend vraiment utile. Après ça, vous n’avez plus jamais besoin du terminal : vous lui envoyez simplement un message.

Discord change ses menus de temps en temps ; si un bouton a bougé, cherchez l’équivalent le plus proche.

  1. Allez sur discord.com/developers/applications et cliquez sur New Application. Donnez-lui le nom que vous voulez.
  2. Dans le menu de gauche, cliquez sur Bot. Faites défiler jusqu’à Privileged Gateway Intents et passez Message Content Intent sur ON. C’est le plus important : si vous l’oubliez, votre bot semblera complètement cassé.
  3. Toujours sur cette page, cliquez sur Reset Token et copiez ce qui s’affiche. Il ne s’affiche qu’une seule fois. Traitez-le comme un mot de passe.
  4. Dans le menu de gauche, cliquez sur Installation. Activez Guild Install, et vérifiez que les scopes incluent bot et applications.commands. Copiez le lien d’installation qu’il vous montre.
  5. Ouvrez ce lien dans votre navigateur et ajoutez le bot à votre serveur. Il faut que ce serveur vous appartienne ou que vous le gériez.
  6. Trouvez votre propre ID utilisateur. Dans Discord, allez dans Paramètres → Avancés, activez le mode développeur, puis faites un clic droit sur votre propre nom et choisissez Copier l’ID utilisateur. C’est un long numéro.
  7. Lancez la configuration et collez le token et l’ID utilisateur :
hermes gateway setup

Choisissez Discord quand il vous le demande. Ensuite, démarrez-le et testez-le :

hermes gateway run

Laissez cette fenêtre ouverte et envoyez au bot un message privé sur Discord. Il devrait répondre. Une fois qu’il répond, appuyez sur Ctrl + C pour l’arrêter, puis exécutez ces deux lignes pour qu’il démarre désormais tout seul : 

hermes gateway install
hermes gateway start
En messages privés il répond à tout. Dans un salon de serveur il ne répond que quand vous le @mentionnez, donc il ne spamme jamais vos amis.
S’il ne répond jamais, c’est presque toujours l’une de ces deux choses : Message Content Intent est encore désactivé, ou l’ID utilisateur a été mal copié. Refaites les étapes 2 et 6.

06Minter des Hashcats (et les drops du même genre)

Certains drops n’ont pas de prix. Au lieu de payer, il faut trouver un numéro chanceux, et le premier qui en trouve un repart avec le chat. C’est ce que les gens veulent dire quand ils disent qu’un mint se résout plutôt qu’il ne s’achète.

Votre ordinateur portable peut le faire, mais il y passerait des jours, alors que des gens avec de grosses machines louées en trouvent en quelques minutes. Vous en louez donc une pour quelques minutes. C’est la seule raison de tout ceci.

Louez un ordinateur pour quelques minutes (gratuit pour commencer)

Modal loue des ordinateurs à la seconde. Vous n’achetez rien. Vous vous inscrivez et vous obtenez $30 de calcul gratuit chaque mois, soit environ sept heures sur leurs machines rapides, à environ $4 de l’heure. Pour des tentatives occasionnelles, vous ne paierez probablement jamais rien.

  1. Inscrivez-vous gratuitement sur modal.com. Les $30 sont déjà inclus.
  2. Exécutez ensuite ces deux commandes une fois :
pip install modal
modal setup

La seconde ouvre un navigateur et relie votre compte. Toute la configuration tient en ça.

Quoi taper dans Discord

Toute l’opération tient en ça. Mentionnez votre bot et collez ceci :

@yourbot use the pow-mint-mining skill on hashcats. show me the current round and get everything ready, but don't spend anything yet

Il vous fait un rapport sur la manche. Quand vous voulez vraiment vous lancer :

@yourbot go ahead and mine the current round. stop when you find one, or after 15 minutes

Et pour voir comment ça s’est passé :

@yourbot did we get one? show me the transaction

Ce qu’il gère pour vous

  • Il vérifie d’abord toute la configuration, pour qu’aucune tentative ne démarre déjà cassée
  • C’est sur l’ordinateur loué qu’il fait la recherche, pas sur le vôtre
  • Il vérifie chaque réponse avant de dépenser quoi que ce soit, donc une réponse arrivée trop tard ne vous coûte jamais de frais
  • Il envoie la transaction depuis votre portefeuille et vous donne le lien

Les deux choses que vous seul pouvez faire

  • Mettez un peu d’ETH dans votre portefeuille. Gagner coûte quand même quelques centimes de frais. Rien ne peut le faire à votre place.
  • Gardez des tentatives courtes. Les manches défilent sans arrêt, et le travail fait pour une manche déjà terminée est perdu. Court et fréquent vaut mieux qu’une longue session.
Soyez lucide sur les probabilités. Vous courez contre tous ceux qui tentent le même drop, et vous payez le calcul, que vous gagniez ou non. C’est à ça que sert le crédit gratuit. Utilisez-le, gardez vos tentatives courtes et ne rechargez pas en espérant un chat garanti.

D’autres drops sur lesquels ça marche

Même principe et même genre de phrase. Vous nommez simplement celui que vous voulez : 

@yourbot use the pow-mint-mining skill on FAB4200 and tell me what it would cost me

07Quoi lui demander

Il n’y a pas de formule magique. Collez un lien et dites ce que vous voulez. Un lien OpenSea, un tweet, un site de mint, une adresse de portefeuille, une adresse de contrat. S’il n’arrive pas à comprendre ce que vous voulez dire, il vous le demande.

Collez un lien OpenSea

@yourbot rank this whole collection by rarity and show me the top 20
@yourbot which rare ones here are listed cheap right now?
@yourbot what is the floor on this and is it going up or down?
@yourbot are the wallets that minted this real people or bots?
@yourbot is this worth buying at the current floor?
@yourbot how many people are holding this, and how concentrated is it?

Collez un tweet qui dit « mintez ça »

C’est la plus utile. Collez le tweet et il détermine ce qu’est le mint, ce qu’il coûte vraiment, s’il est encore ouvert et si le projet a l’air sérieux, avant que quoi que ce soit ne touche à votre portefeuille. 

@yourbot <tweet link> mint this
@yourbot <tweet link> what is this mint and is it real?
@yourbot <tweet link> can I mint this for free?
@yourbot <tweet link> what would minting 3 of these actually cost me?
@yourbot <tweet link> is this the real contract or a copy?
@yourbot <tweet link> set an alert for when this goes live
Il n’envoie pas une transaction à l’aveugle. Il lit le tweet, trouve le contrat, vérifie le prix et l’offre onchain, vous montre ce qu’il a trouvé et attend que vous donniez le feu vert.

Collez un site de mint, ou simplement une adresse de contrat

@yourbot can I mint this for free? <link>
@yourbot what is the real price on this? the page says 0.05
@yourbot is this mint still open or already sold out?
@yourbot how many wallets have minted this so far?
@yourbot is this contract a copy of another collection?
@yourbot what does this contract actually do? <address>

Collez une adresse de portefeuille

@yourbot what has this wallet been buying? <address>
@yourbot is this wallet actually profitable, or just busy?
@yourbot watch this wallet and message me when it buys something
@yourbot which collections did this wallet get into early?
@yourbot does this wallet look like a bot or a person?

Demandez-lui de surveiller quelque chose pour vous

@yourbot watch this collection and message me the moment it reveals
@yourbot tell me when the floor drops below 0.01
@yourbot ping me if anything from this collection sells under 0.005
@yourbot check this every ten minutes and only message me if something changes
@yourbot remind me when this mint opens in an hour

Demandez-lui d’acheter ou de minter pour vous

Chacune de ces demandes vérifie d’abord et vous annonce le coût avant de faire quoi que ce soit. Rien ne passe tant que vous n’avez pas dit feu vert. 

@yourbot mint 1 for me, show me the cost and wait for my go ahead
@yourbot buy the cheapest rare one under 0.01
@yourbot buy 3 but never spend more than 0.03 in total
@yourbot don't spend anything without asking me first
@yourbot what is my wallet holding right now? <address>

Demandez-lui d’expliquer quelque chose

@yourbot explain what a proof of work mint is, in simple terms
@yourbot why is this floor so low?
@yourbot what does "revealed" mean here?
@yourbot how do people fake volume on a collection?
@yourbot what is the difference between a mint and a buy?
La règle générale : si vous pouvez le coller, il peut probablement le regarder. Liens, captures d’écran, adresses, tweets, tableurs. Si vous ne savez pas comment demander, décrivez simplement ce que vous essayez de faire et laissez-le trouver le reste.

08Configurer Vercel

Vercel met gratuitement un site ou une page sur internet. Vous n’en avez pas besoin pour faire tourner l’agent. Il vous le faut si vous voulez votre propre page publique : un lien que vous pouvez partager, un portfolio, une page de documentation, ce guide.

Créer un compte

Inscrivez-vous sur vercel.com/signup avec GitHub, Google ou une adresse e-mail. La formule gratuite suffit pour tout ce qui est présenté ici.

La méthode simple : connecter un projet GitHub

  1. Dans Vercel, cliquez sur Add New → Project.
  2. Connectez votre compte GitHub et choisissez le dépôt que vous voulez mettre en ligne.
  3. Si vos fichiers web sont dans un sous-dossier plutôt qu’à la racine, réglez Root Directory sur ce dossier. Pour la page de ce guide, ce dossier est docs.
  4. Cliquez sur Deploy. Une minute plus tard, vous avez un lien en ligne.

À partir de là, chaque fois que vous poussez vers GitHub, Vercel reconstruit le site tout seul. C’est tout le flux de travail.

La méthode terminal

Si vous préférez déployer directement depuis votre ordinateur :

npm install -g vercel
vercel login

# then, from inside the folder you want online
vercel --prod

Il pose deux ou trois questions la première fois, puis affiche votre lien en ligne.

Déployez la page de ce guide pour essayer

git clone https://github.com/andyemad/nft-mint-rarity-toolkit.git
cd nft-mint-rarity-toolkit
npx vercel deploy docs --prod

Votre propre domaine

Facultatif. Dans les Settings → Domains du projet, vous pouvez ajouter un domaine qui vous appartient, ou accepter l’adresse gratuite your-project.vercel.app qu’il vous donne.

Ce que Vercel ne peut pas faire : faire tourner votre agent. Vercel ne sert que des sites web chargés à la demande. Votre agent est un programme qui doit rester allumé, il vit donc sur votre ordinateur ou sur un serveur. Si vous voyez un déploiement échouer avec une 402 erreur 402, ce compte a dépassé le quota de transfert de la formule gratuite. Créez un nouveau projet, ou utilisez GitHub Pages ou Cloudflare Pages, qui servent les mêmes fichiers.

09Votre ordinateur, un serveur ou de l’hébergement ?

Les deux fonctionnent. La seule vraie différence, c’est ce qui se passe quand vous fermez votre portable.

GRATUIT

Sur votre propre ordinateur

  • Rien à configurer de plus que l’installation déjà faite
  • Pleine vitesse, et il peut utiliser ce que vous seul avez : votre navigateur, vos fichiers, vos portefeuilles
  • S’arrête quand vous fermez le capot ou que vous le mettez en veille
  • Toute tâche planifiée, alerte ou surveillance nocturne rate son créneau
  • Idéal pour : tester des choses, un usage en journée, tout ce que vous surveillez vous-même
~$5 / MOIS

Sur un petit serveur

  • Ne dort jamais. Démarré une fois, il reste en marche
  • Surveillances, alertes et tâches minutées se déclenchent vraiment à 4 h du matin
  • Vous l’atteignez depuis votre téléphone via Discord, où que vous soyez
  • Pas d’écran : vous ne le voyez travailler qu’à travers le chat
  • Idéal pour : les tâches planifiées, les surveillances nocturnes, tout ce que vous voulez faire tourner en continu
TARIFS SUR LE PORTAIL

Ou laissez Nous l’héberger

  • Hermes Cloud fait tourner l’instance pour vous
  • Aucun serveur à installer, à mettre à jour ou à redémarrer vous-même
  • Démarrez-le, arrêtez-le et redémarrez-le depuis une page web, ou en le demandant à votre propre agent
  • La même configuration Discord que partout ailleurs
  • Idéal pour : ceux qui ne veulent pas du tout gérer un serveur

Ou laissez Nous l’héberger pour vous

Si gérer un serveur ressemble à un travail dont vous ne voulez pas, Nous Research héberge des instances Hermes Cloud. Vous obtenez un agent toujours allumé, sans avoir à choisir un fournisseur, sécuriser une machine ou la maintenir à jour.

  1. Créez un Nous Portal compte sur portal.nousresearch.com.
  2. Ouvrez la page Agents et créez une instance. Donnez-lui un nom.
  3. Connectez Discord comme à l’étape 03, exactement. Les mêmes commandes, exécutées sur l’instance.

À partir de là, vous le gérez depuis cette page web. Démarrez-le, arrêtez-le, redémarrez-le ou supprimez-le à cet endroit. Les tarifs sont indiqués sur le portail, à côté des formules.

Un seul abonnement peut couvrir les deux usages. Une formule du portail peut aussi servir de cerveau à l’agent au lieu d’un abonnement séparé à un modèle : elle inclut un large catalogue de modèles, plus la recherche web, la génération d’images et la voix, le tout avec un seul identifiant. Lancez hermes setup --portal et il se configure tout seul. Si vous payez déjà OpenCode, vous n’avez pas besoin des deux.
Vous faites déjà tourner un agent en local ? Vous pouvez gérer vos instances cloud en le lui demandant, plutôt qu’en cliquant partout sur le site. Une commande relie votre agent local au portail : 
hermes mcp add --url https://portal.nousresearch.com/mcp --auth oauth hermes-cloud

Ensuite, vous pouvez dire « liste mes agents cloud », « combien me coûte cette instance » ou « redémarre celle qui est arrêtée ».

Passer à un serveur

  1. Prenez-en un chez Hetzner ou DigitalOcean, environ $5/mois. Choisissez Ubuntu comme système. L’option la plus petite suffit largement.
  2. Suivez la même ligne d’installation Linux de l’étape 02 sur ce serveur plutôt que sur votre ordinateur.
  3. Refaites-y les étapes Discord et compétences. Ce sont les mêmes trois commandes.
  4. Vous pouvez faire tourner les deux. Votre ordinateur et le serveur sont des agents distincts, et chacun a son propre token de bot Discord si vous le souhaitez.
La façon raisonnable de faire : commencez aujourd’hui sur votre propre ordinateur, et ne louez un serveur que quand vous aurez quelque chose que vous voulez faire tourner pendant votre sommeil.
