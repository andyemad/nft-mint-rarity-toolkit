01What you are actually building

Hermes is an AI assistant that runs on your own computer. Unlike ChatGPT, it can actually do things: open pages, read the blockchain, run a script, watch a collection overnight and message you when something happens.

This guide adds 31 ready-made skills to it. A skill is just instructions the assistant loads when a job comes up. You do not run them yourself. You type in Discord, in normal English:

You type: "rank everything in this collection by rarity and tell me which ones are listed cheap"
It does: reads the collection, scores every NFT, pulls the listings, and answers you in the chat.

You never have to touch a terminal again after setup. Discord is where you live. The terminal is just how you turn it on the first time.

03Install the agent

You are going to paste one line into a terminal window. That is the hardest part of the whole guide, and it is just copy and paste.

Windows

Open the Start menu, type PowerShell, click it, and paste this in:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Mac

Press Command + Space, type Terminal, hit Enter, and paste:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Linux

Same as Mac. Open your terminal and paste:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
Either way, the installer does the rest. It downloads everything it needs on its own. It takes a few minutes and you can ignore the text scrolling past.

Check it worked

Close the terminal window, open a fresh one, and type:

hermes doctor

This prints a checklist of everything it needs. Green means fine. If it says something is missing, run the exact command it suggests.

Do you want it running 24/7?

Your own computer is fine, but the agent stops when you shut it down. If you want it awake at 4am watching a reveal while you sleep, rent a small server for about $5 a month from Hetzner or DigitalOcean and pick Ubuntu when they ask which system. Then run the Linux line above on that server instead. That is the whole difference.

04Give it a brain (about $5/month)

An AI agent needs a model to think with, and that is what you pay for. The cheap one that works well here is OpenCode at around $5 a month, running a model called deepseek-v4.1-flash. People are using it for far more than this.

  1. Subscribe here: opencode.ai
  2. Copy the key it shows you. It is a long line of letters and numbers.
  3. Put the key in the agent's settings file.
Windows

Open the settings file in Notepad and paste your key on its own line at the bottom:

notepad $env:USERPROFILE\.hermes\.env

Add this line, replacing YOUR_KEY_HERE with your key, then save and close:

OPENCODE_GO_API_KEY=YOUR_KEY_HERE
Mac and Linux

Run these two lines, replacing YOUR_KEY_HERE with your key:

hermes config env-path
printf 'OPENCODE_GO_API_KEY=%s\n' 'YOUR_KEY_HERE' >> ~/.hermes/.env
The first line just prints where the settings file lives, in case you want to check the key went in. It should look like C:\Users\YourName\.hermes\.env on Windows, or /Users/YourName/.hermes/.env on a Mac.
  1. Tell the agent to use it, and say hello:
hermes model
hermes chat -q "hello, what model are you?"

If it answers you, you have a working agent. Everything after this is just teaching it new tricks.

Watch your usage the first week. Your OpenCode dashboard shows a 5-hour window and a weekly one. Long autonomous jobs use more than chatting, so check the percentage after your first big run.

06Connect Discord

This is the part that makes it feel like a real product. After this, you can talk to your agent from your phone.

  1. Go to discord.com/developers/applications and click New Application. Name it whatever you want.
  2. In the left menu click Bot. Scroll down to Privileged Gateway Intents and switch Message Content Intent to ON. This one matters: without it your bot looks completely broken.
  3. Still on the Bot page, click Reset Token and copy what it gives you. Treat it like a password.
  4. In the left menu click Installation, turn on Guild Install, and make sure the scopes include bot and applications.commands.
  5. Copy the install link it shows you, open it in your browser, and add the bot to your server. You need to own or manage that server.
  6. Get your own Discord user ID. In Discord go to Settings → Advanced, turn on Developer Mode, then right-click your own name and choose Copy User ID. It is a long number.
  7. Now run the setup and paste in the two things you copied:
hermes gateway setup

Choose Discord when it asks. Then start it:

hermes gateway run       # leave this window open and test it

Open Discord and send the bot a direct message. It should answer. Once you are happy, stop it with Ctrl + C and run these two lines so it starts by itself from now on: 

hermes gateway install
hermes gateway start
How it behaves: in direct messages it replies to everything. In a server channel it only replies when you @mention it, so it does not spam your friends.
If it never replies, nine times out of ten it is one of these two: Message Content Intent is still off, or the user ID you pasted is wrong. Redo steps 2 and 6.

07Free GPU minting — the $30 credit

Some NFTs are not sold, they are solved. Instead of paying a price, you have to find a lucky number, and the only way to find it is to try millions of them. That is what people mean by a proof-of-work mint, and it is where Hashcats, FAB4200 and similar drops come from.

Your laptop can do this, but it would take days. A rented graphics card does it in minutes. You do not have to buy one.

Modal gives you $30 of free computing every month on their free plan. That is roughly 7 hours of the fastest graphics cards they rent, at around $4 an hour. For occasional mint attempts, you will likely never pay.
  1. Make a free account at modal.com. The free plan already includes the $30.
  2. Install what you need and connect your account:
pip install modal
modal setup
  1. Check that the fast part works, then try a practice run that spends nothing:
cd toolkit/pow/hashcats-farm
modal run hashcats_modal.py --mode probe
python3 farm.py --shards 2 --minutes 5 --dry

The practice run finds the lucky numbers and checks them, but never sends anything. When you want to do it for real you run the same command without --dry, using a wallet that has a little ETH in it.

Be honest with yourself about this one. GPU minting is a race against everyone else trying the same drop, and you pay for the computing time even when you lose. Use the free credits, keep your attempts short, and do not top up expecting a guaranteed win.

08What every skill does

These are the 31 skills you just installed. You do not need to memorise them. The agent picks the right one automatically. This list is so you know what to ask for.

Minting
nft-mint-recon

Works out what a mint really is

Before you spend anything it finds the real contract, the real price, whether the mint is actually open, and what network it is on. This is the one that stops you from getting scammed by a fake price.

seadrop-rapid-mint

Mints from many wallets at once

For drops that sell out in seconds. It creates fresh wallets, tells you exactly how much to put in each, and fires them all at the moment the mint opens.

pow-mint-mining

Handles proof-of-work mints

The drops where you have to find a lucky number instead of paying. Covers the setup, the rented GPU, and the checking so you never waste a transaction.

onchain-puzzle-mining

Does the number crunching

The actual search for that lucky number, on your machine or on rented hardware, with a self-check so it never runs for hours chasing a broken calculation.

onchain-puzzle-solving

Solves mints that make you think

Riddles, puzzles and hidden clues that gate some drops. It digs through the game's own code to find the answers.

onchain-claim-reverse-engineering

Works out how to claim

For pages that promise a free mint, a refund or an airdrop. It figures out what the site is actually doing before you connect your wallet.

nft-floor-sweep

Prices up buying a whole floor

Adds up every cheap listing in a collection and tells you the real total before you commit to buying them all.

Rarity and sniping
nft-rarity-engine

Ranks a collection by rarity

Scores every single NFT and puts them in order, using the same maths OpenSea uses, so the ranks match. It can even catch a collection right as it reveals, before OpenSea updates.

rh-chain-rarity-sniping

Buys the rare ones cheap

After a reveal, finds the rarest items that are listed at normal floor prices and buys them before anyone else notices.

nft-secondary-buy

Buys a listed NFT for you

Buys from the resale market automatically, always testing the purchase first so a broken order never costs you a fee.

Is this thing real?
nft-minter-legitimacy-audit

Checks if the buyers were real

Looks at who minted a collection and tells you whether they were real people or a handful of wallets faking interest to make it look popular.

web3-claim-verification

Fact-checks a project's claims

When a project says "we did X", this checks the blockchain to see if that is actually true.

nft-market-analysis

Reads the market honestly

Floors, sales, holders, how fast things flip. Tells you what the numbers really say instead of what the project wants you to think.

nft-collection-price-analysis

Sizes up a collection

What it is worth, what could go wrong after you buy, and whether the entry price makes sense for the risk.

nft-exit-discipline

When to sell

Rules for getting out instead of holding forever. The boring skill that saves the most money.

Wallets
ethereum-wallet-operations

Creates and moves wallets safely

Makes new wallets, backs the keys up properly, and moves tokens between them without ever exposing your keys.

wallet-radar-operations

Watches wallets you care about

Follows specific wallets and pings you when they buy something, so you can see what the good traders are doing.

public-wallet-xlsx-delivery

Turns wallets into a spreadsheet

Takes a list of wallets and hands you a clean, shareable spreadsheet instead of a wall of text.

pseudonym-identity-research

Connects anonymous accounts

Links up anonymous social accounts, handles and wallets that belong to the same person.

Making your own collection
nft-collection-production

Builds a collection from scratch

Everything for launching your own: the art plan, the traits, the pricing, the mint page, and the contract mechanics.

nft-trait-taxonomy

Organises the traits

Keeps every attribute consistent and logically grouped, so your metadata does not turn into a mess.

nft-trait-curation

Checks the trait quality

Audits each trait for duplicates, broken ones, and anything that looks off before you launch.

Data, research and building
ethereum-data-pipelines

Reads the blockchain for free

Pulls on-chain data without paying for an API. This is the engine under a lot of the other skills.

rh-mint-command-center

The mint control room

A whole local dashboard for minting: plan a mint, rehearse it, manage a set of wallets, watch the floor, and see exactly what happened afterwards.

mint-field-guide

The mint dashboard

A read-only screen showing upcoming mints, market movement, and what is trending, with a clear note on where every number came from.

onchain-game-economy-analysis

Maps a game's economy

Takes an on-chain game apart to show where value comes from and how it flows.

polymarket

Reads prediction markets

Checks what the betting markets are pricing for an event.

proof-of-play-archive

Proof of Play research

Background research on Proof of Play and Pirate Nation for reference.

agent-protocol-identity

Gives an agent its own identity

Lets an AI agent prove who it is when it posts online, so a real one can be told apart from a fake.

flop-technocore-agent-ops

Running an agent in public

How to give an agent its own account and have it post without leaking anything private.

internet-computer-development

Building on the Internet Computer

Notes and references for a different blockchain, the Internet Computer.

10If something goes wrong

What you seeWhat to do

The bot is online but never answersTurn on Message Content Intent in the Discord developer page. This is the number one cause.
It answers in DMs but not in your serverThat is normal. In servers it only replies when you @mention it.
It says you are not allowedYour Discord user ID is wrong. Copy it again with Developer Mode on.
It stops when you close your laptopExpected if you are running it on your own computer. Get the $5 server for 24/7.
It asks for more moneyCheck your OpenCode usage page. Long jobs use more than chatting. Give it simpler tasks or upgrade.
The skills do not show upRun hermes skills list to check they installed, then /reload-skills in a chat.
You are lostAsk the agent. Type hermes chat and just tell it what you are trying to do in plain English.
