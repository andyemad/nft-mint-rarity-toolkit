02Hermes einrichten

Hermes ist der Agent. Sie fügen eine Zeile in ein Terminalfenster ein, und er installiert sich selbst. Das ist das Technischste in dieser ganzen Anleitung.

Windows

Öffnen Sie das Startmenü, tippen Sie PowerShell, öffnen Sie es und fügen Sie Folgendes ein:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Mac

Drücken Sie Command + Space, tippen Sie Terminal, drücken Sie die Eingabetaste und fügen Sie ein:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Linux

Öffnen Sie Ihr Terminal und fügen Sie ein:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
Es lädt alles, was es braucht, selbst herunter, und dauert ein paar Minuten. Lassen Sie den Text vorbeilaufen, Sie müssen ihn nicht lesen.

Prüfen, ob es geklappt hat

Schließen Sie das Fenster, öffnen Sie ein neues und geben Sie ein:

hermes doctor

Damit wird eine Checkliste ausgegeben. Grün bedeutet in Ordnung. Wenn etwas fehlt, wird Ihnen der genaue Befehl zur Behebung angezeigt.

Geben Sie ihm ein Gehirn

Der Agent braucht ein Modell zum Denken, und das ist das Abo für $10. Registrieren Sie sich hier: opencode.ai.

Fügen Sie dann den Schlüssel, den Sie erhalten, zur Einstellungsdatei hinzu.

Windows 
notepad $env:USERPROFILE\.hermes\.env

Fügen Sie diese Zeile unten hinzu und ersetzen Sie YOUR_KEY_HERE durch Ihren Schlüssel, dann speichern und schließen:

OPENCODE_GO_API_KEY=YOUR_KEY_HERE
Mac und Linux 
printf 'OPENCODE_GO_API_KEY=%s\n' 'YOUR_KEY_HERE' >> ~/.hermes/.env

Sagen Sie ihm nun, dass es das Abo nutzen soll, und begrüßen Sie es:

hermes model
hermes chat -q "hello, what model are you?"

Wenn er antwortet, funktioniert der Agent. Alles danach fügt ihm nur noch Dinge hinzu.

03Discord oder Telegram einrichten

Das ist der Teil, der ihn nützlich macht. Danach brauchen Sie das Terminal nie wieder. Sie schreiben ihm einfach eine Nachricht.

Wählen Sie die App, die Sie bereits nutzen. Beide dauern ein paar Minuten und funktionieren danach gleich.

Discord

Discord ändert seine Menüs ab und zu. Wenn eine Schaltfläche also verschoben ist, suchen Sie die am ehesten passende.

  1. Gehen Sie zu discord.com/developers/applications und klicken Sie auf New Application. Geben Sie ihm einen beliebigen Namen.
  2. Klicken Sie im linken Menü auf Bot. Scrollen Sie zu Privileged Gateway Intents und schalten Sie Message Content Intent auf ON. Dieser Punkt ist am wichtigsten: Lassen Sie ihn weg, und Ihr Bot wirkt völlig kaputt.
  3. Klicken Sie noch auf dieser Seite auf Reset Token und kopieren Sie, was erscheint. Er wird nur einmal angezeigt. Behandeln Sie ihn wie ein Passwort.
  4. Klicken Sie im linken Menü auf Installation. Schalten Sie Guild Install, ein und stellen Sie sicher, dass die Scopes bot und applications.commandsenthalten. Kopieren Sie den Installationslink, der Ihnen angezeigt wird.
  5. Öffnen Sie diesen Link im Browser und fügen Sie den Bot zu Ihrem Server hinzu. Sie müssen diesen Server besitzen oder verwalten.
  6. Finden Sie Ihre eigene Benutzer-ID. Gehen Sie in Discord zu Settings → Advanced, schalten Sie Developer Modeein, klicken Sie dann mit der rechten Maustaste auf Ihren eigenen Namen und wählen Sie Copy User ID. Es ist eine lange Zahl.
  7. Führen Sie das Setup aus und fügen Sie den Token und die Benutzer-ID ein:
hermes gateway setup

Wählen Sie Discord, wenn danach gefragt wird. Starten und testen Sie ihn dann:

hermes gateway run

Lassen Sie dieses Fenster offen und schicken Sie dem Bot in Discord eine Direktnachricht. Er sollte antworten. Sobald er das tut, drücken Sie Ctrl + C , um ihn zu stoppen, und führen Sie diese zwei Zeilen aus, damit er ab dann von selbst startet: 

hermes gateway install
hermes gateway start
In Direktnachrichten antwortet er auf alles. In einem Server-Channel antwortet er nur, wenn Sie ihn mit @ erwähnen, damit er Ihre Freunde nie zuspammt.
Wenn er nie antwortet, liegt es fast immer an einem von zwei Dingen: Der Message Content Intent ist noch aus, oder die Benutzer-ID wurde falsch kopiert. Wiederholen Sie die Schritte 2 und 6.

Telegram

Telegram ist der schnellere Weg. Hermes erstellt den Bot für Sie: Sie scannen einen Code mit Ihrem Smartphone und tippen eine Schaltfläche an.

  1. Führen Sie das Setup aus:
hermes gateway setup
  1. Wählen Sie Telegram , wenn danach gefragt wird, und wählen Sie dann Automatic. Im Fenster erscheint ein quadratischer Code mit einem Link darunter.
  2. Richten Sie die Kamera Ihres Smartphones auf den Code oder öffnen Sie den Link. Telegram öffnet sich und bittet Sie um Bestätigung. Tippen Sie auf Create Bot. Sie können vorher den Namen ändern, wenn Sie möchten.
  3. Zurück im Fenster heißt es, dass Ihr Telegram-Konto erkannt wurde, und Sie werden gefragt, ob es zugelassen werden soll. Sagen Sie ja, und ja zu den paar Fragen danach. Nur Sie können mit dem Bot sprechen.

Starten und testen Sie ihn dann:

hermes gateway run

Lassen Sie dieses Fenster offen, suchen Sie Ihren neuen Bot in Telegram und schicken Sie ihm eine Nachricht. Er sollte antworten. Sobald er das tut, drücken Sie Ctrl + C , um ihn zu stoppen, und führen Sie diese zwei Zeilen aus, damit er ab dann von selbst startet: 

hermes gateway install
hermes gateway start
Möchten Sie den Bot lieber selbst erstellen? Schreiben Sie in Telegram an @BotFather, senden Sie /newbot, und beantworten Sie seine zwei Fragen. Der Benutzername muss auf bot enden. Er gibt Ihnen einen Token: wird nur einmal angezeigt, behandeln Sie ihn wie ein Passwort. Schreiben Sie dann an @userinfobot , um Ihre Benutzer-ID zu erhalten, die eine Zahl ist. Wählen Sie Manual in der Einrichtung und fügen Sie beides ein.
In einem privaten Chat antwortet er auf alles. In einer Gruppe antwortet er nur, wenn Sie ihn mit @ erwähnen oder ihm antworten, damit er Ihre Freunde nie zuspammt. Jeder Prompt später in dieser Anleitung funktioniert hier genauso.
Wenn statt einer Antwort ein Kopplungscode kommt , kennt er Ihr Konto noch nicht. Führen Sie hermes pairing approve telegram <code> im Terminal aus und schreiben Sie ihm erneut.

06Hashcats minten (und ähnliche Drops)

Manche Drops haben keinen Preis. Statt zu zahlen, müssen Sie eine Glückszahl finden, und wer zuerst eine findet, bekommt die Katze. Das meinen Leute, wenn sie sagen, ein Mint wird gelöst statt gekauft.

Ihr Laptop kann das auch, aber es würde Tage dauern, und Leute mit großen gemieteten Rechnern finden sie in Minuten. Also mieten Sie einen für ein paar Minuten. Das ist der einzige Grund für das Ganze.

Mieten Sie einen Computer für ein paar Minuten (Start kostenlos)

Modal vermietet Computer sekundenweise. Sie kaufen nichts. Sie registrieren sich, und es gibt dazu $30 kostenlose Rechenleistung pro Monat, das sind etwa sieben Stunden auf ihren schnellen Maschinen bei rund $4 pro Stunde. Für gelegentliche Versuche zahlen Sie wahrscheinlich nie etwas.

  1. Kostenlos registrieren unter modal.com. Die $30 sind bereits enthalten.
  2. Führen Sie dann einmalig diese zwei Befehle aus:
pip install modal
modal setup

Der zweite öffnet einen Browser und verknüpft Ihr Konto. Das ist die gesamte Einrichtung.

Was Sie in Discord eingeben

Das ist der ganze Vorgang. Erwähnen Sie Ihren Bot und fügen Sie Folgendes ein:

@yourbot nutze den Skill pow-mint-mining für hashcats. Zeig mir die aktuelle Runde und mach alles bereit, aber gib noch nichts aus

Er meldet Ihnen die Runde zurück. Wenn Sie es wirklich versuchen wollen:

@yourbot los, mine die aktuelle Runde. Hör auf, wenn du eine findest, oder nach 15 Minuten

Und um zu sehen, wie es gelaufen ist:

@yourbot haben wir eine bekommen? Zeig mir die Transaktion

Was er für Sie übernimmt

  • Er prüft zuerst die gesamte Einrichtung, damit ein Durchlauf nie kaputt startet
  • Er erledigt die Suche auf dem gemieteten Computer, nicht auf Ihrem
  • Er prüft jede Antwort, bevor er etwas ausgibt, damit eine zu spät eingetroffene Sie nie eine Gebühr kostet
  • Er sendet die Transaktion aus Ihrer Wallet und gibt Ihnen den Link

Die zwei Dinge, die nur Sie erledigen können

  • Legen Sie ein wenig ETH in Ihre Wallet. Selbst beim Gewinnen fallen ein paar Cent an Gebühren an. Das kann nichts für Sie übernehmen.
  • Halten Sie die Versuche kurz. Die Runden wechseln ständig, und Arbeit für eine bereits beendete Runde ist verschwendet. Kurz und häufig schlägt einen langen Durchlauf.
Seien Sie ehrlich zu den Chancen. Sie treten gegen alle an, die denselben Drop versuchen, und Sie zahlen die Rechenleistung, ob Sie gewinnen oder verlieren. Dafür ist das Gratis-Guthaben da. Nutzen Sie es, halten Sie Ihre Versuche kurz und laden Sie nichts auf in der Erwartung einer garantierten Katze.

Andere Drops, bei denen das funktioniert

Dieselbe Idee und dieselbe Art von Prompt. Sie nennen einfach den, den Sie stattdessen möchten: 

@yourbot nutze den Skill pow-mint-mining für FAB4200 und sag mir, was es mich kosten würde

07Was Sie ihn fragen können

Es gibt keine besondere Formulierung. Fügen Sie einen Link ein und sagen Sie, was Sie möchten. Ein OpenSea-Link, ein Tweet, eine Mint-Website, eine Wallet-Adresse, eine Contract-Adresse. Wenn er nicht erkennen kann, was Sie meinen, fragt er nach.

Fügen Sie einen OpenSea-Link ein

@yourbot ranke diese ganze Sammlung nach Seltenheit und zeig mir die Top 20
@yourbot welche seltenen hier werden gerade günstig angeboten?
@yourbot wie hoch ist der Floor und geht er rauf oder runter?
@yourbot sind die Wallets, die das gemintet haben, echte Menschen oder Bots?
@yourbot lohnt sich das beim aktuellen Floor?
@yourbot wie viele Leute halten das, und wie stark ist es konzentriert?

Fügen Sie einen Tweet ein, in dem „mint this“ steht

Das ist der nützliche Fall. Werfen Sie den Tweet ein, und er findet heraus, was der Mint ist, was er wirklich kostet, ob er noch offen ist und ob das Projekt echt wirkt, bevor irgendetwas Ihre Wallet berührt. 

@yourbot <tweet link> mint das
@yourbot <tweet link> was ist dieser Mint und ist er echt?
@yourbot <tweet link> kann ich das kostenlos minten?
@yourbot <tweet link> was würde es mich kosten, 3 davon zu minten?
@yourbot <tweet link> ist das der echte Contract oder eine Kopie?
@yourbot <tweet link> richte einen Alarm ein, wenn das live geht
Er feuert nicht einfach eine Transaktion ab. Er liest den Tweet, findet den Contract, prüft Preis und Supply onchain, zeigt Ihnen, was er gefunden hat, und wartet darauf, dass Sie „los“ sagen.

Fügen Sie eine Mint-Website ein, oder einfach eine Contract-Adresse

@yourbot kann ich das kostenlos minten? <link>
@yourbot was ist der echte Preis dafür? die Seite sagt 0.05
@yourbot ist dieser Mint noch offen oder schon ausverkauft?
@yourbot wie viele Wallets haben das bisher gemintet?
@yourbot ist dieser Contract eine Kopie einer anderen Sammlung?
@yourbot was macht dieser Contract eigentlich? <address>

Fügen Sie eine Wallet-Adresse ein

@yourbot was hat diese Wallet in letzter Zeit gekauft? <address>
@yourbot ist diese Wallet wirklich profitabel oder nur beschäftigt?
@yourbot beobachte diese Wallet und schreib mir, wenn sie etwas kauft
@yourbot bei welchen Sammlungen war diese Wallet früh dabei?
@yourbot sieht diese Wallet wie ein Bot oder wie ein Mensch aus?

Bitten Sie ihn, etwas für Sie zu beobachten

@yourbot beobachte diese Sammlung und schreib mir in dem Moment, in dem sie revealed wird
@yourbot sag mir, wenn der Floor unter 0.01 fällt
@yourbot ping mich, wenn etwas aus dieser Sammlung unter 0.005 verkauft wird
@yourbot prüf das alle zehn Minuten und schreib mir nur, wenn sich etwas ändert
@yourbot erinnere mich, wenn dieser Mint in einer Stunde öffnet

Bitten Sie ihn, für Sie zu kaufen oder zu minten

Jeder dieser Fälle prüft zuerst und nennt Ihnen die Kosten, bevor er etwas tut. Nichts geht durch, bis Sie „los“ sagen. 

@yourbot mint 1 für mich, zeig mir die Kosten und warte auf mein Okay
@yourbot kauf das günstigste seltene unter 0.01
@yourbot kauf 3, aber gib insgesamt nie mehr als 0.03 aus
@yourbot gib nichts aus, ohne mich vorher zu fragen
@yourbot was hält meine Wallet gerade? <address>

Bitten Sie ihn, etwas zu erklären

@yourbot erklär mir in einfachen Worten, was ein Proof-of-Work-Mint ist
@yourbot warum ist dieser Floor so niedrig?
@yourbot was bedeutet hier „revealed“?
@yourbot wie täuschen Leute Volumen bei einer Sammlung vor?
@yourbot was ist der Unterschied zwischen einem Mint und einem Kauf?
Die allgemeine Regel: wenn Sie es einfügen können, kann er es sich wahrscheinlich ansehen. Links, Screenshots, Adressen, Tweets, Tabellen. Wenn Sie nicht sicher sind, wie Sie fragen sollen, beschreiben Sie einfach, was Sie erreichen möchten, und lassen Sie ihn den Rest herausfinden.
Möchten Sie ändern, wie ein Skill selbst funktioniert? Das ist eine eigene Seite, denn es ist das Nützlichste, was Sie hier lernen können: die Skills durch Reden besser machen.

08Vercel einrichten

Vercel stellt eine Website oder eine Seite kostenlos ins Internet. Sie brauchen es nicht, um den Agenten zu betreiben. Sie brauchen es, wenn Sie eine eigene öffentliche Seite möchten: einen Link zum Teilen, ein Portfolio, eine Dokumentationsseite, diese Anleitung.

Konto anlegen

Registrieren Sie sich unter vercel.com/signup mit GitHub, Google oder E-Mail. Der kostenlose Tarif reicht für alles hier.

Der einfache Weg: ein GitHub-Projekt verbinden

  1. Klicken Sie in Vercel auf Add New → Project.
  2. Verbinden Sie Ihr GitHub-Konto und wählen Sie das Repository, das online gehen soll.
  3. Wenn Ihre Web-Dateien in einem Ordner statt auf der obersten Ebene liegen, setzen Sie Root Directory auf diesen Ordner. Für die Seite dieser Anleitung ist das der Ordner docs.
  4. Klicken Sie auf Deploy. Eine Minute später haben Sie einen Live-Link.

Ab dann baut Vercel die Seite bei jedem Push zu GitHub von selbst neu. Das ist der ganze Workflow.

Der Weg über das Terminal

Wenn Sie lieber direkt von Ihrem Computer aus deployen möchten:

npm install -g vercel
vercel login

# then, from inside the folder you want online
vercel --prod

Beim ersten Mal werden ein paar Fragen gestellt, dann wird Ihr Live-Link ausgegeben.

Die Seite dieser Anleitung als Testlauf deployen

git clone https://github.com/andyemad/nft-mint-rarity-toolkit.git
cd nft-mint-rarity-toolkit
npx vercel deploy docs --prod

Ihre eigene Domain

Optional. In den Settings → Domains des Projekts können Sie eine Domain hinzufügen, die Ihnen gehört, oder die kostenlose your-project.vercel.app Adresse annehmen, die Ihnen gegeben wird.

Was Vercel nicht kann: Ihren Agenten betreiben. Vercel liefert nur Websites aus, die bei Bedarf geladen werden. Ihr Agent ist ein Programm, das eingeschaltet bleiben muss, also lebt er auf Ihrem Computer oder auf einem Server. Wenn Sie jemals einen Deploy mit einem 402 Fehler sehen, hat dieses Konto das Transferkontingent des kostenlosen Tarifs überschritten. Erstellen Sie ein neues Projekt, oder nutzen Sie GitHub Pages oder Cloudflare Pages, die dieselben Dateien ausliefern.

09Ihr Computer, ein Server oder gehostet?

Beides funktioniert. Der einzige echte Unterschied ist, was passiert, wenn Sie Ihr Laptop zuklappen.

KOSTENLOS

Auf Ihrem eigenen Computer

  • Nichts einzurichten außer der Installation, die Sie schon gemacht haben
  • Volle Geschwindigkeit, und er kann Dinge nutzen, die nur Sie haben: Ihren Browser, Ihre Dateien, Ihre Wallets
  • Hört auf, wenn Sie den Deckel schließen oder ihn in den Ruhemodus versetzen
  • Jeder geplante Job, Alarm oder Nacht-Watch verpasst sein Zeitfenster
  • Gut für: Ausprobieren, Nutzung am Tag, alles, was Sie selbst beobachten
~$5 / MONAT

Auf einem kleinen Server

  • Schläft nie. Einmal gestartet, läuft er durch
  • Watches, Alarme und zeitgesteuerte Jobs feuern tatsächlich um 4 Uhr nachts
  • Sie erreichen ihn von überall über Ihr Smartphone und Discord
  • Kein Bildschirm, Sie sehen ihn also nur über den Chat arbeiten
  • Gut für: geplante Jobs, Nacht-Watches, alles, was ständig laufen soll
PREISE IM PORTAL

Oder lassen Sie Nous ihn hosten

  • Hermes Cloud betreibt die Instanz für Sie
  • Kein Server, den Sie selbst einrichten, patchen oder neu starten müssen
  • Starten, stoppen und neu starten über eine Webseite oder indem Sie Ihren eigenen Agenten fragen
  • Dieselbe Discord-Einrichtung wie überall sonst
  • Gut für: Leute, die überhaupt keinen Server betreiben wollen

Oder lassen Sie Nous es für Sie hosten

Wenn ein eigener Server nach Arbeit klingt, die Sie nicht wollen, hostet Nous Research Instanzen von Hermes Cloud. Sie bekommen einen Agenten, der immer läuft, ohne einen Anbieter auszuwählen, eine Maschine abzusichern oder sie aktuell zu halten.

  1. Erstellen Sie ein Nous Portal Konto unter portal.nousresearch.com.
  2. Öffnen Sie die Agents -Seite und erstellen Sie eine Instanz. Geben Sie ihr einen Namen.
  3. Verbinden Sie Discord oder Telegram genau wie in Schritt 03 damit. Dieselben Befehle, ausgeführt auf der Instanz.

Ab dann verwalten Sie sie über diese Webseite. Dort starten, stoppen, neu starten oder löschen. Die Preise stehen im Portal neben den Tarifen.

Ein Abo kann beide Aufgaben abdecken. Ein Portal-Tarif kann auch das Gehirn des Agenten sein, statt eines separaten Modell-Abos: Er enthält einen großen Katalog von Modellen plus verwaltete Websuche, Bildgenerierung und Stimme, alles über einen Login. Führen Sie hermes setup --portal aus, und er verbindet sich selbst. Wenn Sie bereits für OpenCode zahlen, brauchen Sie nicht beides.
Läuft bei Ihnen schon ein Agent lokal? Sie können Ihre Cloud-Instanzen verwalten, indem Sie ihn fragen, statt auf der Webseite herumzuklicken. Ein Befehl verbindet Ihren lokalen Agenten mit dem Portal: 
hermes mcp add --url https://portal.nousresearch.com/mcp --auth oauth hermes-cloud

Danach können Sie sagen „list my cloud agents“, „what is that instance costing me“ oder „restart the stopped one“.

Umzug auf einen Server

  1. Holen Sie sich einen bei Hetzner oder DigitalOcean, etwa $5/Monat. Wählen Sie Ubuntu als System. Die kleinste Option reicht völlig.
  2. Folgen Sie derselben Linux-Installationszeile aus Schritt 02 auf diesem Server statt auf Ihrem Computer.
  3. Wiederholen Sie dort die Discord- und Skill-Schritte. Es sind dieselben drei Befehle.
  4. Sie können beides betreiben. Ihr Computer und der Server sind getrennte Agenten, und jeder bekommt bei Bedarf seinen eigenen Discord-Bot-Token.
Vernünftiger Weg: Starten Sie heute auf Ihrem eigenen Computer und mieten Sie erst dann einen Server, wenn Sie etwas haben, das laufen soll, während Sie schlafen.
