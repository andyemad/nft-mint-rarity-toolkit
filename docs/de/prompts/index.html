Vibe coding

Die Skills sind nicht alle fertig.Formen Sie sie im Gespräch.

Einige der 31 Skills sind noch etwas rau. Das ist Absicht: Sie reparieren und erweitern sie, indem Sie beschreiben, was Sie wollen. Sie schreiben nie Code. Sie sagen, was kaputt ist oder was hinzukommen soll, und Ihr Agent setzt es um, testet es und zeigt Ihnen das Ergebnis.

Holen Sie sich das Abo Zurück zum Einrichtungsleitfaden

01Was Vibe coding wirklich bedeutet

Normalerweise bedeutet es, Software zu verbessern, dass ein Entwickler den Code liest und ihn bearbeitet. Hier überspringen Sie das. Sie beschreiben das Problem in normalen Worten, und der Agent übernimmt das Lesen und das Bearbeiten.

Ein Skill ist nichts weiter als eine schriftlich festgehaltene Anleitung, der Ihr Agent folgt. Ihn zu verbessern ist also keine Programmierarbeit, sondern ein Gespräch. Sie sagen „das schlägt ständig fehl, wenn jemand ihm einen Robinhood-Link gibt“, und er geht hin und behebt es.

Warum es sich lohnt: Jeder Skill, den Sie verbessern, bleibt verbessert. Wenn diese Aufgabe das nächste Mal ansteht, kennt der Agent die Antwort bereits.
Keine separate Rechnung. Das läuft über dasselbe Abo, das Sie bereits eingerichtet haben. Lange Aufträge verbrauchen mehr davon als ein Gespräch, schauen Sie also bei den ersten paar auf Ihre Nutzungsseite und machen Sie sich danach keine Gedanken mehr.

02Der Vier-Schritte-Kreislauf

SCHRITT 1

Sagen Sie, was Sie wollen

In klaren Worten, in Discord. Wenn Sie es einer Person beschreiben können, können Sie es auch hier beschreiben.

SCHRITT 2

Lassen Sie es arbeiten

Es liest den Skill, überlegt, was geändert werden muss, und nimmt die Änderung vor. Bitten Sie es, in einer Zeile zu erklären, was es getan hat.

SCHRITT 3

Lassen Sie es das beweisen

Sagen Sie „teste es und zeig mir die Ausgabe“. Das ist der Schritt, den die Leute überspringen, und genau der zählt.

SCHRITT 4

Wiederholen, bis es stimmt

Wenn es nicht stimmt, sagen Sie, was noch falsch ist. Zwei oder drei Runden sind normal.

„Fertig“ ist kein Ergebnis. Ein Agent kann Ihnen erzählen, er sei mit etwas fertig, das nicht funktioniert. Verlangen Sie immer die tatsächliche Ausgabe, den tatsächlichen Fehler oder den tatsächlichen Link. Wenn er es Ihnen nicht zeigen kann, ist es nicht fertig.

04Wenn einer kaputtgeht

Das ist das, was Sie am häufigsten tun werden, und es ist völlig normal. Etwas wirft einen Fehler, Sie fügen den Fehler wieder ein, und es wird behoben.

@yourbot das hat nicht funktioniert. das hat es gesagt: <paste the whole error>

@yourbot wie beim letzten Mal, aber mit dieser Wallet-Adresse: <address>

@yourbot finde heraus, warum das immer wieder fehlschlägt, statt es einfach nochmal zu versuchen

@yourbot geh zurück zum vorherigen Zustand, diese Änderung hat es schlimmer gemacht

@yourbot du hast gesagt, es funktioniert, aber das tut es nicht. zeig mir den Beweis, dass es funktioniert, bevor du das nochmal sagst
Fügen Sie den ganzen Fehler ein, nicht eine Zusammenfassung. Die hässliche Textwand ist genau das, was er braucht. Wenn Sie sie kürzen, dauern Korrekturen vier Versuche statt einen.
Wenn es schlimmer wird, bitten Sie um ein Zurücksetzen. „Geh zurück zum vorherigen Zustand“ ist ein legitimer und nützlicher Prompt. Bitten Sie es, vor großen Änderungen eine Kopie zu speichern, damit das immer möglich ist.

05Bringen Sie ihm etwas Neues bei

Die 31 Skills sind ein Ausgangspunkt. Der eigentliche Wert liegt darin, eigene hinzuzufügen, für Dinge, die Sie immer wieder tun.

@yourbot schau zu, wie ich einen Mint vor dem Kauf prüfe, und schreib dann einen Skill, damit du das nächste Mal für mich erledigen kannst

@yourbot erstelle einen Skill, um Kollektionen zu finden, deren Floor gerade gefallen ist

@yourbot jedes Mal, wenn ich einen Tweet einfüge, solltest du prüfen, ob es ein Mint ist, was er kostet und ob er echt ist. mach daraus einen Skill

@yourbot erstelle einen Skill, der alle meine Wallets prüft und mir sagt, was ich mir ansehen sollte

@yourbot bau etwas, das zwei Kollektionen nebeneinander vergleicht und mir sagt, welche die besseren Chancen hat
Machen Sie aus allem Wiederkehrenden einen Skill. Wenn Sie dasselbe zweimal erklärt haben, ist das ein Skill. Sie müssen es nie ein drittes Mal erklären.

06Bauen Sie eine ganze kleine Sache

Dieselbe Idee, nur größer. Sie können eine funktionierende Seite bauen und online stellen lassen – dafür ist der Vercel-Teil im Einrichtungsleitfaden da.

@yourbot baue mir eine Seite, die jede Kollektion zeigt, die ich halte, mit Bildern und Seltenheitsrang

@yourbot baue ein einfaches Dashboard der Kollektionen, die ich beobachte, und stell es auf Vercel

@yourbot mach eine Seite, auf der ich einen Kollektionslink einfügen kann, die alles nach Seltenheit ordnet und Bilder zeigt

@yourbot stell das auf Vercel und gib mir den Link, wenn es tatsächlich online ist
Verlangen Sie den Live-Link, kein „Fertig“. Wenn es sagt, die Seite sei online, verlangen Sie die URL und öffnen Sie sie selbst. Diese eine Gewohnheit fängt die meisten Arten ab, wie das schiefgeht.

07Sätze, die funktionieren

Sagen Sie dasUnd Sie bekommen
„zeig mir deinen Plan, bevor du anfängst“Sie sehen, was es vorhat, bevor es etwas tut, und können es umlenken
„teste es und zeig mir die Ausgabe“Der Unterschied zwischen einer echten Korrektur und einem selbstsicheren Satz
„erkläre in einer Zeile, was du geändert hast“Sie behalten die Kontrolle, ohne Code zu lesen
„gib nichts aus / ändere noch nichts“Es übernimmt das Nachdenken, ohne Ihr Geld oder Ihre Dateien anzufassen
„mach es einfacher“Es entfernt das Ausgeklügelte und lässt etwas übrig, dem Sie folgen können
„ich verstehe das nicht, erklär es mir, als wäre ich neu dabei“Eine klare Antwort statt Fachjargon
„geh zurück zum vorherigen Zustand“Ein Rückgängigmachen, wenn eine Änderung es schlimmer gemacht hat
„speichere das als Skill“Es wird dauerhaft, und Sie erklären es nie wieder

08Ärger vermeiden

  • Fügen Sie niemals einen Private Key ein in einen Chat mit einem Agenten oder sonst irgendwohin. Falls Sie es je getan haben, betrachten Sie diese Wallet als verbrannt und verschieben Sie alles, was darin liegt.
  • Verlangen Sie den Plan vor großen Änderungen. „Zeig mir zuerst den Plan“ kostet Sie zehn Sekunden und erspart Ihnen ein Durcheinander.
  • Eine Änderung nach der anderen. Drei Verbesserungen auf einmal bedeuten, dass Sie nicht erkennen können, welche es kaputt gemacht hat.
  • Halten Sie Ihr Geld hinter einem „Nein“. Sagen Sie „gib nichts aus, ohne mich zu fragen“, und es wird nichts ausgeben.
  • Machen Sie eine Sicherung, bevor Sie tiefer gehen. Bitten Sie es, vorher eine Kopie Ihrer Skills zu speichern: „kopiere meinen Skills-Ordner an einen sicheren Ort“.
  • Wenn es Erfolg behauptet und Sie ihn nicht sehen können, ist er nicht real. Fragen Sie noch einmal nach dem Beweis.

All das braucht eine Sache

Das Abo, etwa $10 im Monat, mit deepseek v4.1 flash. Es bietet eine wirklich großzügige Nutzungsmenge, und genau das macht dieses Hin und Her zu etwas, das Sie den ganzen Tag machen können, ohne auf einen Zähler zu schauen.
