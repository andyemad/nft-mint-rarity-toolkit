02Hermesをセットアップ

Hermesがそのエージェントです。ターミナルに1行貼り付ければ自分でインストールします。このガイドで最も技術的なのはここだけです。

Windows

スタートメニューを開いて入力: PowerShell を開き、これを貼り付けます:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Mac

押します Command + Space を押して入力: Terminal を押してEnterキー、そして貼り付けます:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Linux

ターミナルを開いて貼り付けてください:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
必要なものはすべて自動でダウンロードされ、数分かかります。流れるテキストは読み飛ばして構いません。

うまくいったか確認する

ウィンドウを閉じて、新しいものを開き、入力してください:

hermes doctor

チェックリストが表示されます。緑なら問題ありません。不足があれば、直すための正確なコマンドを教えてくれます。

頭脳を与える

エージェントには考えるためのモデルが必要で、それが$10のサブスクです。こちらから登録してください: opencode.ai.

次に、発行されたキーを設定ファイルに追加します。

Windows 
notepad $env:USERPROFILE\.hermes\.env

末尾にこの行を追加し、 YOUR_KEY_HERE を自分のキーに置き換えて、保存して閉じます:

OPENCODE_GO_API_KEY=YOUR_KEY_HERE
MacとLinux 
printf 'OPENCODE_GO_API_KEY=%s\n' 'YOUR_KEY_HERE' >> ~/.hermes/.env

次にサブスクを使うよう設定し、挨拶してみます:

hermes model
hermes chat -q "hello, what model are you?"

答えが返ってくれば、エージェントは動いています。ここから先は機能を足していくだけです。

03DiscordまたはTelegramをセットアップ

ここが使いものにするパートです。これ以降ターミナルは不要で、メッセージを送るだけになります。

すでに使っているほうのアプリを選んでください。どちらも数分で終わり、その後の使い方は同じです。

Discord

Discordはメニューが時々変わります。ボタンの場所が違う場合は、一番近いものを探してください。

  1. アクセスします discord.com/developers/applications を開き、クリック: New Application 名前は何でも構いません。
  2. 左メニューでクリック: Bot までスクロールし、 Privileged Gateway Intents を切り替えます: Message Content Intent を ON に。ここが最も重要です。忘れるとボットが完全に壊れているように見えます。
  3. 同じページで次をクリックします: トークンをリセット 表示された値をコピーします。一度しか表示されないので、パスワードと同じように扱ってください。
  4. 左メニューでクリック: インストール. 次をオンにします: サーバーインストール、スコープに次が含まれていることを確認します: bot と applications.commands。表示されたインストールリンクをコピーします。
  5. そのリンクをブラウザで開き、ボットを自分のサーバーに追加します。そのサーバーの所有者または管理者である必要があります。
  6. 自分のユーザーIDを調べます。Discordで次を開きます: 設定 → 詳細設定に進み、次をオンにします: 開発者モード、次に自分の名前を右クリックして次を選びます: ユーザーIDをコピー。長い数字です。
  7. セットアップを実行し、トークンとユーザーIDを貼り付けます:
hermes gateway setup

尋ねられたらDiscordを選びます。次に起動してテストします:

hermes gateway run

そのウィンドウは開いたままにして、Discordでボットにダイレクトメッセージを送ります。返信が来るはずです。来たら次を押します: Ctrl + C で停止し、次の2行を実行して、以降は自動で起動するようにします: 

hermes gateway install
hermes gateway start
ダイレクトメッセージでは すべてに返信します。 サーバーのチャンネルでは @メンションされたときだけ返信するので、友達にスパムを送ることはありません。
返信がまったく来ない場合、ほぼ次の2つのどちらかです。「メッセージ内容インテント」がオフのままか、ユーザーIDのコピーを間違えています。手順2と6をやり直してください。

Telegram

Telegramのほうが手早く済みます。Hermesがボットを作ってくれます。スマホでコードを読み取り、ボタンを1つ押すだけです。

  1. セットアップを実行します:
hermes gateway setup
  1. 次を選びます: Telegram と尋ねられたら、次に選びます: Automatic。ウィンドウに四角いコードが表示され、その下にリンクがあります。
  2. スマホのカメラをコードに向けるか、リンクを開きます。Telegramが開き、確認を求められます。次をタップします: ボットを作成。先に名前を変えてもかまいません。
  3. ウィンドウに戻ると、Telegramアカウントを検出したと表示され、許可するか尋ねられます。はいを選び、続くいくつかの質問にもはいと答えます。ボットと話せるのはあなただけです。

次に起動してテストします:

hermes gateway run

そのウィンドウは開いたままにして、Telegramで新しいボットを見つけ、メッセージを送ります。返信が来るはずです。来たら次を押します: Ctrl + C で停止し、次の2行を実行して、以降は自動で起動するようにします: 

hermes gateway install
hermes gateway start
自分でボットを作りたいですか? Telegramで次にメッセージを送ります: @BotFatherに、次を送信します: /newbot。2つの質問に答えます。ユーザー名は次で終わる必要があります: bot。トークンが渡されます。一度しか表示されないので、パスワードと同じように扱ってください。次にメッセージを送ります: @userinfobot 。これで数字のユーザーIDがわかります。次を選びます: Manual をセットアップで選び、両方を貼り付けます。
個別チャットでは すべてに返信します。 グループでは @メンションするか返信したときだけ答えるので、友達にスパムを送ることはありません。このガイドの以降のプロンプトもすべて同じように使えます。
ペアリングコードが返ってきた場合 ではなく、まだあなたのアカウントを認識していません。次を実行します: hermes pairing approve telegram <code> をターミナルで実行し、もう一度メッセージを送ります。

04スキルをダウンロードする

3行です。スキルをダウンロードして、あなたのエージェントにインストールします:

git clone https://github.com/andyemad/nft-mint-rarity-toolkit.git
cd nft-mint-rarity-toolkit
./install.sh

いつでも次で確認できます: hermes skills list。あとでインストーラーをもう一度実行しても問題ありません。何も壊れません。

gitが入っていない、または自信がない場合 次からZIPをダウンロードします: このリンク。解凍し、そのフォルダでターミナルを開いて次を実行します: bash install.sh.

最後に、ウォレットと取引のスキルが必要とする小さなヘルパーが3つあります:

pip install eth-account coincurve pycryptodome

06Hashcats（および類似のドロップ）をミントする

価格のないドロップもあります。支払う代わりにラッキーナンバーを 見つける必要があり、最初に見つけた人がその猫を手に入れます。これが、ミントは買うのではなく 解くものだと言われる所以です。

自分のノートパソコンでもできますが、何日もかかります。一方、大きなレンタル コンピュータを使う人は数分で見つけます。だから数分だけ借りるのです。それが この仕組みの唯一の理由です。

コンピュータを数分だけ借りる（無料で始められます）

Modal はコンピュータを秒単位で貸し出します。何も買う必要はありません。登録すると 次のものが付いてきます 毎月 $30 分の無料コンピューティング、これは時速およそ $4 の高速マシンで約7時間分に相当します。たまに試す程度なら、 おそらく一切支払うことはありません。

  1. 無料登録はこちら： modal.com。 $30 分はすでに含まれています。
  2. 次に、この2つのコマンドを一度だけ実行します：
pip install modal
modal setup

2つ目はブラウザを開いてアカウントを連携します。設定はこれだけです。

Discord で入力する内容

操作はこれだけです。ボットにメンションして、これを貼り付けてください：

@yourbot hashcats で pow-mint-mining を使って。何も使う前にラウンド、難易度、当たる確率を見せて
@yourbot 今のラウンドを回して。ヒットしたら、または15分で止めて、どちらにせよコストを教えて
@yourbot 獲れた？トランザクションを見せて、そのあともう1回やる価値があるか教えて

ラウンドの内容を報告してくれます。実際に挑戦したくなったら：

@yourbot そのまま今のラウンドをマイニングして。見つけたら、または15分たったら止めて

結果を確認するには：

@yourbot 獲れた？トランザクションを見せて

代わりにやってくれること

  • まず設定全体をチェックするので、壊れた状態で実行が始まることはありません
  • 探索はあなたのマシンではなく、借りたコンピュータで行います
  • 何かを使う前にすべての答えを確認するので、遅すぎた答えで手数料を払うことはありません
  • あなたのウォレットからトランザクションを送信し、そのリンクを教えてくれます

あなたにしかできない2つのこと

  • ウォレットに少しの ETH を入れておいてください。 当たっても手数料として数セントかかります。この部分は誰にも代われません。
  • 試行は短く保ってください。 ラウンドは次々と進み、すでに終わったラウンドのためにした計算は無駄になります。一度の長い実行より、短く頻繁にのほうが効果的です。
当たる確率には正直でいてください。 同じドロップに挑む全員と競争していて、勝っても負けても コンピューティング費用はかかります。無料クレジットはそのためのものです。 それを使い、試行は短く保ち、確実に猫が手に入ると思って追加チャージはしないでください。

08Vercel をセットアップする

Vercel はウェブサイトやページを無料でインターネットに公開します。エージェントを 動かすのに必要ではありません。自分の公開ページが欲しいときに必要です：共有できる リンク、ポートフォリオ、ドキュメントページ、このガイドなど。

アカウントを作成する

まずは登録から vercel.com/signup でGitHub、Google、またはメールアドレスを使って登録してください。ここで紹介する内容はすべて無料プランで足ります。

かんたんな方法：GitHubプロジェクトを連携する

  1. Vercelで Add New → Project.
  2. をクリックします。GitHubアカウントを連携し、公開したいリポジトリを選んでください。
  3. Webファイルが最上位ではなくフォルダの中にある場合は、 Root Directory にそのフォルダを設定してください。このガイドのページではそのフォルダは docs.
  4. クリックします Deploy。1分ほどで公開リンクが手に入ります。

以降はGitHubにプッシュするたびに、Vercelが自動でサイトを再ビルドします。 これがワークフローのすべてです。

ターミナルから行う方法

パソコンから直接デプロイしたい場合はこちらです：

npm install -g vercel
vercel login

# then, from inside the folder you want online
vercel --prod

初回にいくつか質問されるので答えるだけで、公開リンクが表示されます。

試しにこのガイドのページをデプロイしてみる

git clone https://github.com/andyemad/nft-mint-rarity-toolkit.git
cd nft-mint-rarity-toolkit
npx vercel deploy docs --prod

独自ドメインを使う

任意です。プロジェクトの Settings → Domains で、自分が所有するドメインを追加できます。そのまま無料で your-project.vercel.app 割り当てられるアドレスを使ってもかまいません。

Vercelができないこと： エージェントを動かすことです。Vercelは必要に応じて読み込まれるWebサイトしか配信できません。エージェントは常に起動している必要があるプログラムなので、あなたのパソコンかサーバー上で動かします。デプロイが次のエラーで失敗する場合は 402 、そのアカウントが無料プランの転送量を使い切ったということです。 新しいプロジェクトを作るか、同じファイルを配信できるGitHub PagesやCloudflare Pagesを使ってください。

09自分のパソコン、サーバー、それともホスティング？

どれでも動きます。本当の違いは、ノートパソコンを閉じたときに何が起きるかだけです。

無料

自分のパソコンで動かす

  • すでに済ませたインストール以外に準備は不要
  • 最高速度で動き、あなただけが持つもの（ブラウザ、ファイル、ウォレット）も使えます
  • ふたを閉じるか スリープさせると止まります
  • 定時ジョブやアラート、夜通しの監視はその時間帯を逃します
  • 向いている用途：試してみたいとき、日中だけの利用、自分で見ているものすべて
月額約$5

小さなサーバーで動かす

  • 眠りません。一度起動すれば動き続けます
  • 監視やアラート、定時ジョブが午前4時でもきちんと動きます
  • どこからでもスマホからDiscord経由で操作できます
  • 画面がないので、チャット以外では動いている様子を見られません
  • 向いている用途：定時ジョブ、夜通しの監視、常に動かしておきたいものすべて
料金はポータルで確認できます

Nousにホスティングを任せる

  • Hermes Cloud がインスタンスを代わりに運用します
  • サーバーの設定やパッチ当て、再起動を自分で行う必要はありません
  • Webページから、あるいは自分のエージェントに頼んで起動・停止・再起動できます
  • Discordの設定はほかの方法と同じです
  • 向いている用途：サーバーを一切動かしたくない人

Nousにホスティングを任せるのも手です

サーバーの運用が面倒に感じるなら、 Nous Researchが Hermes Cloudインスタンスをホスティングします。プロバイダーを選んだり、サーバーを保護したり、更新し続けたりすることなく、常時稼働のエージェントが手に入ります。

  1. 次の場所で Nous Portal アカウントを作成します： portal.nousresearch.com.
  2. を開き、 Agents ページでインスタンスを作成してください。名前を付けます。
  3. DiscordまたはTelegramの連携は、手順03とまったく同じです。同じコマンドを インスタンス上で実行します。

以降はそのWebページから管理します。起動、停止、再起動、削除もそこで行えます。料金はプランとあわせてポータルに記載されています。

1つの契約で両方をまかなえます。 ポータルのプランは、別途モデルの契約をせずに エージェントの頭脳としても使えます。多数のモデルのカタログに加えて、管理されたWeb検索、画像生成、音声が1つのログインで使えます。実行するには hermes setup --portal と入力すれば自動で設定されます。すでにOpenCodeを契約しているなら、両方は必要ありません。
すでにローカルでエージェントを動かしていますか？ Webサイトをあちこちクリックする代わりに、 エージェントに頼んでクラウドインスタンスを管理できます。コマンド1つでローカルの エージェントをポータルに接続できます： 
hermes mcp add --url https://portal.nousresearch.com/mcp --auth oauth hermes-cloud

あとは「クラウドのエージェント一覧を出して」「あのインスタンスにいくらかかっている？」「止まっているのを再起動して」と言うだけです。

サーバーに移行する

  1. HetznerやDigitalOceanで月額約$5で借りられます。システムには Ubuntu を選んでください。最小構成で十分です。
  2. 手順02のLinuxインストール用のコマンドを、自分のパソコンではなくそのサーバーで実行してください。
  3. そこでDiscordとスキルの手順も繰り返します。同じコマンド3つだけです。
  4. 両方を動かしてもかまいません。パソコンとサーバーは別々のエージェントで、望むならそれぞれに専用のDiscordボットトークンを持たせられます。
おすすめの進め方： 今日は自分のパソコンで始め、眠っている間も動かしたいものができたときにだけ サーバーを借ります。
