02Hermes 설정

Hermes가 바로 그 에이전트입니다. 터미널 창에 한 줄만 붙여넣으면 스스로 설치됩니다. 이 가이드 전체에서 가장 기술적인 부분이 바로 여기입니다.

Windows

시작 메뉴를 열고 PowerShell을 입력한 뒤 열고, 다음을 붙여넣으세요:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Mac

먼저 Command + Space를 입력한 다음 Terminal을 입력하고 Enter를 누른 뒤 붙여넣으세요:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Linux

터미널을 열고 붙여넣으세요:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
필요한 것은 스스로 모두 내려받으며 몇 분 정도 걸립니다. 텍스트가 지나가도 그냥 두세요, 읽을 필요 없습니다.

제대로 됐는지 확인

창을 닫고 새 창을 연 뒤 입력하세요:

hermes doctor

체크리스트가 출력됩니다. 초록색이면 정상입니다. 빠진 항목이 있으면 고치는 정확한 명령어를 알려줍니다.

두뇌를 달아주세요

에이전트가 생각할 모델이 필요한데, 그것이 바로 $10 구독입니다. 여기서 가입하세요: opencode.ai.

그다음 발급받은 키를 설정 파일에 추가하세요.

Windows 
notepad $env:USERPROFILE\.hermes\.env

맨 아래에 이 줄을 추가하되, YOUR_KEY_HERE 다음 부분을 본인의 키로 바꾼 뒤 저장하고 닫으세요:

OPENCODE_GO_API_KEY=YOUR_KEY_HERE
Mac 및 Linux 
printf 'OPENCODE_GO_API_KEY=%s\n' 'YOUR_KEY_HERE' >> ~/.hermes/.env

이제 구독을 사용하라고 지정하고 인사를 건네보세요:

hermes model
hermes chat -q "hello, what model are you?"

답이 오면 에이전트가 작동하는 것입니다. 이후의 모든 과정은 여기에 기능을 더하는 것뿐입니다.

03Discord 또는 Telegram 설정

이 부분이 에이전트를 쓸모 있게 만듭니다. 이걸 마치면 터미널은 다시 필요 없습니다. 그냥 메시지만 보내면 됩니다.

이미 쓰고 있는 앱을 고르세요. 둘 다 몇 분이면 되고, 이후에는 같게 동작합니다.

Discord

Discord는 가끔 자체 메뉴를 바꾸므로, 버튼이 옮겨졌다면 가장 비슷한 것을 찾으세요.

  1. 이동하세요: discord.com/developers/applications 그리고 클릭하세요: 새 애플리케이션. 이름은 아무거나 붙이세요.
  2. 왼쪽 메뉴에서 클릭하세요: 봇. 아래로 스크롤해 권한 게이트웨이 인텐트 에서 메시지 콘텐츠 인텐트 를 ON으로 바꾸세요. 이 항목이 가장 중요합니다: 건너뛰면 봇이 완전히 망가진 것처럼 보입니다.
  3. 아직 그 페이지에서 Reset Token 을 클릭하고 나타나는 값을 복사하세요. 한 번만 표시되니 비밀번호처럼 다루세요.
  4. 왼쪽 메뉴에서 클릭하세요: 설치. 켜세요 Guild Install, 그리고 스코프에 다음이 포함되어 있는지 확인하세요 bot 와 applications.commands. 표시되는 설치 링크를 복사하세요.
  5. 그 링크를 브라우저에서 열고 봇을 서버에 추가하세요. 해당 서버를 소유하거나 관리하고 있어야 합니다.
  6. 본인의 사용자 ID를 찾으세요. Discord에서 Settings → Advanced, 켜세요 Developer Mode, 그다음 본인 이름을 우클릭하고 선택하세요 Copy User ID. 긴 숫자입니다.
  7. 설정을 실행하고 토큰과 사용자 ID를 붙여넣으세요:
hermes gateway setup

물어보면 Discord를 선택하세요. 그다음 시작하고 테스트하세요:

hermes gateway run

그 창을 열어 둔 채 Discord에서 봇에게 DM을 보내세요. 답장이 와야 합니다. 답장이 오면 Ctrl + C 를 눌러 중지하고, 다음부터 자동으로 시작되도록 아래 두 줄을 실행하세요: 

hermes gateway install
hermes gateway start
개인 메시지에서는 모든 것에 답합니다. 서버 채널에서는 당신이 @멘션할 때만 답하므로 친구들에게 도배하지 않습니다.
답장이 전혀 없다면, 거의 항상 두 가지 중 하나입니다: Message Content Intent가 꺼져 있거나 사용자 ID를 잘못 복사한 경우입니다. 2단계와 6단계를 다시 하세요.

Telegram

Telegram이 더 빠릅니다. Hermes가 봇을 만들어 줍니다: 휴대폰으로 코드를 스캔하고 버튼 하나만 누르면 됩니다.

  1. 설정을 실행하세요:
hermes gateway setup
  1. 물어보면 Telegram 다음 중에서 고르세요: Automatic. 창에 정사각형 코드가 나타나고 그 아래에 링크가 있습니다.
  2. 휴대폰 카메라를 코드에 비추거나 링크를 여세요. Telegram이 열리고 확인을 요청합니다. 다음을 누르세요 Create Bot. 원한다면 먼저 이름을 바꿔도 됩니다.
  3. 창으로 돌아오면 Telegram 계정을 감지했다고 알려주고 허용할지 묻습니다. 예를 누르고, 이어지는 몇 가지 질문에도 예를 누르세요. 봇과 대화할 수 있는 사람은 본인뿐입니다.

그다음 시작하고 테스트하세요:

hermes gateway run

그 창을 열어 둔 채 Telegram에서 새 봇을 찾아 메시지를 보내세요. 답장이 와야 합니다. 답장이 오면 Ctrl + C 를 눌러 중지하고, 다음부터 자동으로 시작되도록 아래 두 줄을 실행하세요: 

hermes gateway install
hermes gateway start
봇을 직접 만들고 싶나요? Telegram에서 다음에게 메시지를 보내세요 @BotFather, 다음을 입력하세요 /newbot, 그리고 두 가지 질문에 답하세요. 사용자 이름은 다음으로 끝나야 합니다: bot. 그러면 토큰을 줍니다: 한 번만 표시되니 비밀번호처럼 다루세요. 그다음 다음에게 메시지를 보내세요 @userinfobot 를 보내 사용자 ID(숫자)를 확인하세요. 설정에서 Manual 을 선택하고 두 값을 모두 붙여넣으세요.
개인 채팅에서는 모든 것에 답합니다. 그룹에서는 @멘션하거나 답장할 때만 답하므로 친구들에게 도배하지 않습니다. 이 가이드의 이후 모든 프롬프트도 여기서 동일하게 작동합니다.
답장으로 페어링 코드가 온다면 답변 대신 왔다면, 아직 당신 계정을 모르는 것입니다. 실행하세요: hermes pairing approve telegram <code> — 터미널에서 실행하고 다시 메시지를 보내세요.

04스킬 다운로드

세 줄입니다. 스킬을 다운로드해 에이전트에 설치합니다:

git clone https://github.com/andyemad/nft-mint-rarity-toolkit.git
cd nft-mint-rarity-toolkit
./install.sh

언제든지 다음으로 확인하세요: hermes skills list. 나중에 설치 프로그램을 다시 실행해도 안전하며 아무것도 망가지지 않습니다.

git이 설치되어 있지 않거나 잘 모르겠나요? 다음에서 ZIP을 다운로드하세요: 이 링크, 압축을 풀고 그 폴더에서 터미널을 열어 실행하세요: bash install.sh.

마지막으로, 지갑과 트레이딩 스킬에 필요한 작은 도우미 세 가지입니다:

pip install eth-account coincurve pycryptodome

06Hashcats 민팅하기 (그와 비슷한 드롭도)

일부 드롭에는 가격이 없습니다. 돈을 내는 대신 행운의 숫자를 찾아야 하고, 가장 먼저 찾은 사람이 그 캣을 가져갑니다. 사람들이 민팅을 "사는 것"이 아니라 "푸는 것"이라고 말할 때 뜻하는 게 바로 이것입니다.

노트북으로도 할 수 있지만 며칠이 걸리고, 큰 장비를 빌린 사람들은 몇 분 만에 찾아냅니다. 그래서 몇 분 동안 장비를 빌립니다. 이 모든 이유가 그것뿐입니다.

몇 분 동안 컴퓨터 빌리기 (무료로 시작)

Modal 컴퓨터를 초 단위로 빌려줍니다. 따로 사는 건 없습니다. 가입하면 다음이 함께 제공됩니다. 매달 $30 상당의 무료 컴퓨팅이는 대략 시간당 $4인 고속 장비를 약 일곱 시간 쓸 수 있는 양입니다. 가끔씩만 시도한다면 아마 한 푼도 낼 일이 없을 겁니다.

  1. 무료 가입: modal.com. $30은 이미 포함되어 있습니다.
  2. 그다음 아래 두 명령어를 한 번 실행하세요:
pip install modal
modal setup

두 번째 명령은 브라우저를 열어 계정을 연결합니다. 설정은 이게 전부입니다.

대신 처리해 주는 것들

  • 시작 전에 전체 설정을 먼저 점검하므로, 실행 도중 문제가 생기지 않습니다
  • 탐색은 내 컴퓨터가 아니라 빌린 컴퓨터에서 돌립니다
  • 무엇이든 쓰기 전에 모든 답을 검증하므로, 너무 늦게 도착한 답 때문에 수수료를 낼 일이 없습니다
  • 내 지갑에서 트랜잭션을 보내고 링크를 알려드립니다

나만 할 수 있는 두 가지

  • 지갑에 ETH를 조금 넣어 두세요. 이겨도 수수료로 몇 센트는 나갑니다. 그 부분은 아무것도 대신할 수 없습니다.
  • 시도는 짧게 유지하세요. 라운드는 계속 바뀌고, 이미 끝난 라운드에 한 작업은 버려집니다. 길게 한 번보다 짧게 여러 번이 낫습니다.
확률에 대해 솔직해지세요. 같은 드롭에 도전하는 사람들과 경쟁하는 것이고, 이기든 지든 컴퓨팅 비용은 냅니다. 무료 크레딧은 바로 그걸 위해 있는 것입니다. 잘 쓰고, 시도는 짧게 유지하고, 무조건 캣을 얻는다는 기대에 돈을 더 넣지는 마세요.

Vercel은 웹사이트나 페이지를 무료로 인터넷에 올려줍니다. 에이전트를 돌리는 데 꼭 필요한 건 아닙니다. 내 공개 페이지가 필요할 때 쓰면 됩니다: 공유할 수 있는 링크, 포트폴리오, 문서 페이지, 이 가이드 같은 것 말이죠.

계정 만들기

가입 주소: vercel.com/signup GitHub, Google 또는 이메일로 가입하면 됩니다. 여기 있는 모든 것에는 무료 플랜으로 충분합니다.

쉬운 방법: GitHub 프로젝트 연결하기

  1. Vercel에서 클릭하세요: Add New → Project.
  2. GitHub 계정을 연결하고 온라인에 올릴 저장소를 고르세요.
  3. 웹 파일이 최상위가 아니라 폴더 안에 있다면 Root Directory 를 그 폴더로 지정하세요. 이 가이드의 페이지에서는 그 폴더가 docs.
  4. 클릭하세요: Deploy. 1분 뒤면 라이브 링크가 생깁니다.

그다음부터는 GitHub에 푸시할 때마다 Vercel이 사이트를 알아서 다시 빌드합니다. 워크플로는 그게 전부입니다.

터미널로 하는 방법

컴퓨터에서 바로 배포하고 싶다면:

npm install -g vercel
vercel login

# then, from inside the folder you want online
vercel --prod

처음 한 번 몇 가지 질문을 하고 나서 라이브 링크를 출력합니다.

테스트 삼아 이 가이드의 페이지를 배포해 보세요

git clone https://github.com/andyemad/nft-mint-rarity-toolkit.git
cd nft-mint-rarity-toolkit
npx vercel deploy docs --prod

나만의 도메인

선택 사항입니다. 프로젝트의 Settings → Domains 에서 보유한 도메인을 추가하거나, 무료로 받는 your-project.vercel.app 주소를 그대로 써도 됩니다.

Vercel이 할 수 없는 일: 에이전트를 실행하는 것입니다. Vercel은 요청이 있을 때 불러오는 웹사이트만 제공합니다. 에이전트는 계속 켜져 있어야 하는 프로그램이라 컴퓨터나 서버에서 돌아갑니다. 배포가 이런 오류로 실패한다면 402 오류라면 그 계정이 무료 플랜의 전송 한도를 넘은 것입니다. 새 프로젝트를 만들거나, 같은 파일을 제공하는 GitHub Pages나 Cloudflare Pages를 쓰세요.

09내 컴퓨터, 서버, 아니면 호스팅?

둘 다 됩니다. 실제로 다른 점은 노트북을 닫았을 때 벌어지는 일뿐입니다.

무료

내 컴퓨터에서

  • 이미 한 설치 말고는 따로 설정할 게 없습니다
  • 속도가 최고이고, 브라우저·파일·지갑처럼 나만 가진 것들을 쓸 수 있습니다
  • 노트북 덮개를 닫으면 멈춥니다 또는 절전 모드에 들어가면
  • 예약 작업이나 알림, 밤샘 감시가 정해진 시간을 놓칩니다
  • 어울리는 용도: 이것저것 시험해 보기, 낮 시간 사용, 직접 지켜보는 작업
월 ~$5

작은 서버에서

  • 잠들지 않습니다. 한 번 켜면 계속 돌아갑니다
  • 감시와 알림, 예약 작업이 새벽 4시에도 제대로 실행됩니다
  • 어디서든 휴대폰에서 Discord로 접속할 수 있습니다
  • 화면이 없어서 채팅으로만 작동하는 모습을 볼 수 있습니다
  • 어울리는 용도: 예약 작업, 밤샘 감시, 항상 돌리고 싶은 작업
가격은 포털에서 확인

아니면 Nous가 호스팅하게 하세요

  • Hermes Cloud 가 인스턴스를 대신 운영합니다
  • 서버를 직접 설치하거나 패치하거나 재시작할 필요가 없습니다
  • 웹 페이지에서, 또는 내 에이전트에게 말해서 시작·중지·재시작할 수 있습니다
  • Discord 설정은 다른 경우와 똑같습니다
  • 어울리는 대상: 서버를 아예 돌리고 싶지 않은 사람

아니면 Nous에 호스팅을 맡기세요

서버 운영이 하기 싫은 일처럼 들린다면, Nous Research가 Hermes Cloud 인스턴스를 호스팅합니다. 제공자를 고르거나 서버를 확보하거나 계속 업데이트할 필요 없이 항상 켜져 있는 에이전트를 얻습니다.

  1. 다음에서 Nous Portal 계정을 만드세요: portal.nousresearch.com.
  2. 다음 페이지를 여세요: Agents 페이지에서 인스턴스를 만들고 이름을 붙여 주세요.
  3. 03단계와 똑같이 Discord나 Telegram을 연결하세요. 같은 명령을 인스턴스에서 실행하면 됩니다.

그다음부터는 그 웹 페이지에서 관리합니다. 거기서 시작·중지·재시작·삭제하세요. 가격은 포털에 요금제와 함께 안내되어 있습니다.

구독 하나로 두 역할을 모두 해결할 수 있습니다. 포털 요금제는 별도 모델 구독 대신 에이전트의 두뇌가 될 수도 있습니다. 다양한 모델 카탈로그와 관리형 웹 검색, 이미지 생성, 음성까지 로그인 하나로 모두 제공합니다. 다음을 실행하면 hermes setup --portal 알아서 연결됩니다. 이미 OpenCode를 결제하고 있다면 둘 다 필요하지는 않습니다.
이미 로컬에서 에이전트를 돌리고 있나요? 웹사이트를 이리저리 클릭하는 대신 에이전트에게 말해서 클라우드 인스턴스를 관리할 수 있습니다. 명령 하나로 로컬 에이전트를 포털에 연결합니다: 
hermes mcp add --url https://portal.nousresearch.com/mcp --auth oauth hermes-cloud

그 뒤에는 "내 클라우드 에이전트 목록 보여줘", "저 인스턴스에 얼마 나가고 있어", "멈춘 거 재시작해"라고 하면 됩니다.

서버로 옮기기

  1. Hetzner나 DigitalOcean에서 월 약 $5에 하나 구하세요. 다음을 고르세요: Ubuntu 를 시스템으로 선택하세요. 가장 작은 옵션으로 충분합니다.
  2. 02단계의 같은 Linux 설치 명령을 내 컴퓨터 대신 그 서버에서 실행하세요.
  3. Discord와 스킬 단계도 거기서 반복하세요. 똑같은 명령 세 개면 됩니다.
  4. 둘 다 돌려도 됩니다. 컴퓨터와 서버는 별개의 에이전트이고, 원하면 각각 고유한 Discord 봇 토큰을 쓰면 됩니다.
현명한 방법: 오늘은 내 컴퓨터에서 시작하고, 자는 동안에도 돌리고 싶은 게 생겼을 때만 서버를 빌리세요.

보이는 증상이렇게 하세요
hermes 명령이 인식되지 않음터미널을 닫고 새로 여세요. 그래도 안 되면 컴퓨터를 재시작하고 다시 시도하세요.
봇은 온라인인데 답이 없음Discord 개발자 페이지에서 Message Content Intent가 꺼져 있습니다. 가장 흔한 원인입니다.
DM에서는 답하는데 서버에서는 조용함정상입니다. 서버에서는 @멘션할 때만 답합니다.
권한이 없다고 함Discord 사용자 ID가 잘못되었습니다. 개발자 모드를 켜고 다시 복사하세요.
Telegram이 페어링 코드로 답함아직 계정을 인식하지 못한 상태입니다. 다음을 실행하세요: hermes pairing approve telegram <code> 터미널에서 실행한 뒤 다시 메시지를 보내세요.
Vercel 배포가 402로 실패함그 계정이 무료 전송 한도를 넘었습니다. 새 프로젝트를 만들거나 GitHub Pages나 Cloudflare Pages를 쓰세요.
밤사이 에이전트가 멈춤내 컴퓨터에서 돌던 경우입니다. 정상적인 현상이며, 항상 켜져 있어야 한다면 서버로 옮기세요.
돈을 더 내라고 함OpenCode 사용량 페이지를 확인하세요. 긴 작업은 채팅보다 사용량이 많습니다.
스킬이 나타나지 않음hermes skills list 로 설치 여부를 확인한 뒤 /reload-skills 채팅에서 실행하세요.
막막할 때다음을 실행하세요: hermes chat 그리고 하려는 일을 그냥 설명하면 됩니다.
