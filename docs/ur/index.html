02Hermes setup karein

Hermes hi agent hai. Aap terminal window mein ek line paste karte hain aur ye khud install ho jata hai. Is poori guide mein sab se technical cheez yahi hai.

Windows

Start menu kholein, likhein PowerShell, ise kholein aur ye paste karein:

iex (irm https://hermes-agent.nousresearch.com/install.ps1)

Mac

Dabayein Command + Space, likhein Terminal, Enter dabayein aur paste karein:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash

Linux

Apna terminal kholein aur paste karein:

curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
Ye jo bhi chahiye khud download kar leta hai aur kuch minute leta hai. Text ko guzarne dein, ise parhne ki zarurat nahi.

Check karein ke ho gaya

Window band karein, nayi kholein aur likhein:

hermes doctor

Ye ek checklist dikhata hai. Green ka matlab theek hai. Agar kuch missing ho to ye batata hai ke usay theek karne wali exact command kya hai.

Ise dimagh dein

Agent ko sochne ke liye ek model chahiye, aur wohi $10 wali subscription hai. Yahan sign up karein: opencode.ai.

Phir jo key ye deta hai usay settings file mein add karein.

Windows 
notepad $env:USERPROFILE\.hermes\.env

Neeche ye line add karein, aur iski jagah YOUR_KEY_HERE apni key daalein, phir save kar ke band karein:

OPENCODE_GO_API_KEY=YOUR_KEY_HERE
Mac aur Linux 
printf 'OPENCODE_GO_API_KEY=%s\n' 'YOUR_KEY_HERE' >> ~/.hermes/.env

Ab ise batayein ke subscription use kare aur hello kahein:

hermes model
hermes chat -q "hello, what model are you?"

Agar jawab de de to agent chal raha hai. Is ke baad sab kuch usme cheezein add karna hai.

03Discord ya Telegram setup karein

Yahi woh hissa hai jo ise kaam ka banata hai. Is ke baad terminal ki zarurat kabhi nahi padegi. Aap sirf message karte hain.

Jo app aap pehle se use karte hain wohi chunein. Dono mein kuch minute lagte hain aur baad mein bilkul ek jaise kaam karte hain.

Discord

Discord apne menus waqt waqt par badalta hai, to agar koi button hil gaya ho to sab se milta julta dhoondein.

  1. Yahan jayein discord.com/developers/applications aur click karein New Application. Koi bhi naam dein.
  2. Bayein menu mein click karein Bot. Neeche scroll karein Privileged Gateway Intents aur on karein Message Content Intent ko ON. Ye sab se zaroori hai: ise skip kiya to aap ka bot bilkul toota hua lagega.
  3. Usi page par rehte hue click karein Reset Token aur jo aaye usay copy karein. Ye sirf ek baar dikhta hai. Isay password ki tarah rakhein.
  4. Bayein menu mein click karein Installation. On karein Guild Install, aur check karein ke scopes mein ye shamil hain bot aur applications.commands. Jo install link ye dikhata hai usay copy karein.
  5. Us link ko browser mein kholein aur bot ko apne server mein add karein. Us server ke aap owner ya manager hone chahiye.
  6. Apni user ID dhoondein. Discord mein jayein Settings → Advanced, on karein Developer Mode, phir apne naam par right-click karein aur chunein Copy User ID. Ye ek lamba number hai.
  7. Setup chalayein aur token aur user ID paste karein:
hermes gateway setup

Jab poochhe to Discord chunein. Phir ise start karein aur test karein:

hermes gateway run

Woh window khuli chhoriye aur Discord mein bot ko direct message bhejein. Ise jawab dena chahiye. Jab de de to dabayein Ctrl + C ise rokne ke liye, aur ye do lines chalayein taake is ke baad ye khud start ho: 

hermes gateway install
hermes gateway start
Direct messages mein ye har cheez ka jawab deta hai. Server channel mein ye sirf tab jawab deta hai jab aap @mention karein, to aap ke friends ko spam nahi hoga.
Agar ye kabhi jawab na de, to taqreeban hamesha do mein se ek baat hoti hai: Message Content Intent abhi bhi off hai, ya user ID ghalat copy hui. Steps 2 aur 6 dobara karein.

Telegram

Telegram zyada tez tareeqa hai. Hermes aap ke liye bot banata hai: aap phone se ek code scan karte hain aur ek button dabate hain.

  1. Setup chalayein:
hermes gateway setup
  1. Chunein Telegram jab ye poochhe, phir chunein Automatic. Window mein ek square code aata hai, aur us ke neeche ek link hota hai.
  2. Apne phone ka camera code par karein, ya link kholein. Telegram khulta hai aur confirm karne ko kehta hai. Dabayein Create Bot. Chahein to pehle iska naam badal sakte hain.
  3. Wapas window mein ye kehta hai ke is ne aap ka Telegram account detect kar liya hai aur poochta hai ke ijazat deni hai ya nahi. Haan kehein, aur us ke baad aane wale do chaar sawalon par bhi haan. Bot se sirf aap hi baat kar sakte hain.

Phir ise start karein aur test karein:

hermes gateway run

Woh window khuli chhoriye, Telegram mein apna naya bot dhoondein, aur usay message bhejein. Ise jawab dena chahiye. Jab de de to dabayein Ctrl + C ise rokne ke liye, aur ye do lines chalayein taake is ke baad ye khud start ho: 

hermes gateway install
hermes gateway start
Bot khud banana pasand karte hain? Telegram mein message karein @BotFather, bhejein /newbot, aur us ke dono sawalon ka jawab dein. Username ka aakhir bot par hona zaroori hai. Ye aap ko ek token deta hai: sirf ek baar dikhta hai, isay password ki tarah rakhein. Phir message karein @userinfobot apni user ID lene ke liye, jo ek number hai. Chunein Manual setup mein aur dono paste karein.
Private chat mein ye har cheez ka jawab deta hai. Group mein ye sirf tab jawab deta hai jab aap @mention karein ya isay reply karein, to aap ke friends ko spam nahi hoga. Is guide ke baad aane wale har prompt yahan bhi waise hi kaam karte hain.
Agar ye jawab ki jagah pairing code bheje to is ka matlab ye abhi aap ka account nahi jaanta. Terminal mein hermes pairing approve telegram <code> chalayein aur phir se message karein.

06Hashcats mint karein (aur aise drops)

Kuch drops ki koi price nahi hoti. Paise dene ki jagah aap ko ek lucky number dhoondna hota hai, aur jo pehle dhoond le wohi cat le jata hai. Jab log kehte hain ke mint kharida nahi, solve kiya jata hai, to matlab yahi hota hai.

Aap ka laptop ye kar sakta hai, lekin din lag jayenge, aur bade kiraye ke computers wale minute mein dhoond lete hain. To aap kuch minute ke liye ek kiraye par lete hain. Is sab ki sirf yahi wajah hai.

Kuch minute ke liye computer kiraye par lein (shuru karna free)

Modal second ke hisaab se computers kiraye deta hai. Aap kuch nahi kharidte. Aap sign up karte hain aur is ke saath milta hai har mahine $30 ka free computing, jo taqreeban saat ghante un ki tez machines ka hota hai, lagbhag $4 fi ghanta. Kabhi kabhi try karne ke liye aap ko shayad kabhi paise nahi dene parenge.

  1. Free sign up karein modal.com. $30 pehle se shamil hai.
  2. Phir ye do commands ek baar chalayein:
pip install modal
modal setup

Doosra browser kholta hai aur aap ka account link karta hai. Poora setup bas itna hai.

Discord mein kya likhna hai

Poora kaam bas itna hai. Apne bot ko mention karein aur ye paste karein:

@yourbot hashcats par pow-mint-mining use karo. kuch bhi kharch karne se pehle round, difficulty aur mere odds dikhao
@yourbot current round chalao. hit par ya 15 minute par ruk jao, aur dono soorat mein cost batao
@yourbot mila ya nahi? transaction dikhao, phir batao doosra attempt paise ke laayak hai ya nahi

Ye round ki report aap ko deta hai. Jab waqai koshish karni ho:

@yourbot aage barhein aur current round mine karein. jab ek mil jaye to ruk jayein, ya 15 minute ke baad

Aur ye dekhne ke liye ke kya hua:

@yourbot kya humein ek mila? mujhe transaction dikhayein

Ye aap ke liye kya sambhalta hai

  • Pehle poora setup check karta hai, to koi run kharab haalat mein shuru nahi hota
  • Searching kiraye ke computer par karta hai, aap ke computer par nahi
  • Kuch kharch karne se pehle har jawab check karta hai, taake der se aane wale jawab par aap ki fee na lage
  • Transaction aap ke wallet se bhejta hai aur link aap ko deta hai

Sirf do kaam jo aap hi kar sakte hain

  • Apne wallet mein thora ETH daalein. Jeetne par bhi fees mein kuch cents lagte hain. Woh hissa koi aap ke liye nahi kar sakta.
  • Koshishein chhoti rakhein. Rounds musalsal badalte rehte hain, aur jo round khatam ho chuka us ka kaam zaya jata hai. Chhoti aur baar baar wali koshish ek lambi run se behtar hai.
Odds ke baare mein sach kehein. Aap un sab se race kar rahe hain jo wohi drop try kar rahe hain, aur jeetein ya haarein, computing ke paise aap dete hain. Free credit isi ke liye hai. Ise use karein, koshishein chhoti rakhein, aur guaranteed cat ki umeed par paise na daalein.

Doosre drops jahan ye kaam karta hai

Wohi idea aur wohi tarah ka prompt. Aap sirf apna wala naam lein: 

@yourbot FAB4200 par pow-mint-mining use karo. ek poora attempt mujhe kitne ka parega, aur aaj ki difficulty par is ka faida hai?

Ek tweet paste karein jismein likha ho "ye mint karein"

Ye sab se kaam ki cheez hai. Tweet daalein aur ye pata kar leta hai ke mint kya hai, asal mein kitne paise lagte hain, abhi bhi khula hai ya nahi, aur project asli lagta hai ya nahi — ye sab wallet ko chhune se pehle. 

@yourbot <tweet link> ise chhoone se pehle: asli mint price, supply, kitne wallets ne mint kiya, aur kya ye deployer pehle bhi kisi mint se bhag chuka hai
@yourbot <tweet link> kya contract kisi mojooda collection ki copy hai? dikhao kya kya bilkul same hai
@yourbot <tweet link> 3 mint karne ka total kharcha kya hoga, gas samet?
@yourbot <tweet link> is ke peeche kaun hai? koi public wallet, koi linked project
@yourbot <tweet link> ye abhi bhi open hai ya already sold out?
@yourbot <tweet link> ise watch karo aur live hote hi mujhe ping karo
Ye seedha transaction nahi bhej deta. Tweet parhta hai, contract dhoondta hai, price aur supply on-chain check karta hai, jo mila woh aap ko dikhata hai, aur aap ke haan kehne ka intezar karta hai.

Mint website paste karein, ya sirf ek contract address

@yourbot <address> kya ye honeypot hai? ek mint aur ek transfer simulate karo, phir batao kya tootta hai
@yourbot <address> ye contract asal mein karta kya hai? aasan lafzon mein, code ke baghair
@yourbot kitne wallets ne mint kiya hai, aur pehle bees ek hi cluster lagte hain?
@yourbot <address> is deployer ne aur collections bhi launch ki hain? woh kaisi rahin?
@yourbot <address> koi owner switch, pause, ya supply cap hai jo mere mint ke baad badal sakta hai?

Wallet address paste karein

@yourbot un pichhli teen collections par early hone wale das wallets dhoond do jo achhi gayi thi
@yourbot kya <address> is ke deployer se connected hai ? funding trace karo

08Vercel setup karein

Vercel internet par free mein website ya page daalta hai. Agent chalane ke liye iski zarurat nahi. Iski zarurat tab hai jab aap ko apna public page chahiye: share karne wala link, portfolio, documentation page, ye guide.

Account banayein

Sign up karein vercel.com/signup GitHub, Google ya email se. Yahan sab kuch ke liye free plan kaafi hai.

Aasan tareeqa: GitHub project connect karein

  1. Vercel mein click karein Add New → Project.
  2. Apna GitHub account connect karein aur woh repository chunein jo online karni hai.
  3. Agar aap ki web files top level ki jagah kisi folder mein hain, to set karein Root Directory us folder par. Is guide ke page ka woh folder ye hai docs.
  4. Click karein Deploy. Ek minute baad aap ke paas live link hoga.

Is ke baad jab bhi aap GitHub par push karein, Vercel khud site dobara build kar deta hai. Poora workflow bas itna hai.

Terminal wala tareeqa

Agar aap seedha apne computer se deploy karna chahein:

npm install -g vercel
vercel login

# then, from inside the folder you want online
vercel --prod

Pehli baar do chaar sawal poochta hai aur phir aap ka live link print karta hai.

Test ke liye is guide ka page deploy karein

git clone https://github.com/andyemad/nft-mint-rarity-toolkit.git
cd nft-mint-rarity-toolkit
npx vercel deploy docs --prod

Apna domain

Optional. Project ke Settings → Domains mein aap apna domain add kar sakte hain, ya jo free your-project.vercel.app address ye deta hai usay accept kar lein.

Vercel kya nahi kar sakta: aap ka agent chalana. Vercel sirf woh websites serve karta hai jo on demand load hoti hain. Aap ka agent ek program hai jo on rehna hota hai, is liye ye aap ke computer ya server par rehta hai. Agar kabhi deploy aise fail ho 402 error ke saath, to woh account free plan ki transfer allowance se aage nikal gaya hai. Naya project banayein, ya GitHub Pages ya Cloudflare Pages use karein, jo wohi files serve karte hain.

Ya Nous se host karwayein

Agar server chalana aisa kaam lagta hai jo aap nahi karna chahte, Nous Research Hermes Cloud instances host karta hai. Aap ko hamesha on rehne wala agent milta hai, bina provider chune, bina box secure kiye aur bina usay update rakhe.

  1. Banayein Nous Portal account yahan portal.nousresearch.com.
  2. Kholein Agents page aur ek instance banayein. Ise koi naam dein.
  3. Discord ya Telegram ko is se bilkul step 03 ki tarah connect karein. Wohi commands, instance par chalayein.

Is ke baad aap usay usi web page se manage karte hain. Wahan se start, stop, restart ya delete karein. Pricing Portal par plans ke saath likhi hoti hai.

Ek hi subscription dono kaam kar sakti hai. Portal plan alag model subscription ki jagah agent ka dimagh bhi ban sakta hai: ismein models ka bara catalogue plus managed web search, image generation aur voice shamil hai, sab ek hi login se. Chalayein hermes setup --portal aur ye khud set up ho jata hai. Agar aap pehle se OpenCode ke paise de rahe hain to dono ki zarurat nahi.
Pehle se agent locally chala rahe hain? Aap website par clicks karne ki jagah apne agent se keh kar cloud instances manage kar sakte hain. Ek command aap ke local agent ko Portal se connect karti hai: 
hermes mcp add --url https://portal.nousresearch.com/mcp --auth oauth hermes-cloud

Is ke baad aap keh sakte hain "mere cloud agents list karein", "woh instance kitna kharcha kar raha hai", ya "jo ruk gaya hai usay restart karein".

Server par shift hona

  1. Hetzner ya DigitalOcean se ek lein, taqreeban $5/month. Chunein Ubuntu system ke liye. Sab se chhota option kaafi hai.
  2. Step 02 wali wohi Linux install line apne computer ki jagah us server par chalayein.
  3. Wahan Discord aur skills ke steps dobara karein. Wohi teen commands hain.
  4. Aap dono chala sakte hain. Aap ka computer aur server alag agents hain, aur chahein to har ek ka apna Discord bot token hota hai.
Samajhdari wala tareeqa: aaj apne computer par shuru karein, aur server sirf tab kiraye par lein jab aap ke paas kuch aisa ho jo sote waqt bhi chalna chahiye.
