Vibe coding

Ye skills sab mukammal nahi hain.Baat karke inhe theek karein.

31 skills mein se kuch abhi adhoore hain. Ye jaan bujh kar aisa hai: aap sirf ye batayein ke aap kya chahte hain, aur aap inhe theek aur behtar karte hain. Aap kabhi code nahi likhte. Aap batate hain ke kya kharab hai ya kya add karna hai, aur aapka agent wo karta hai, test karta hai, aur aapko result dikhata hai.

01Vibe coding ka asal matlab kya hai

Aam tor par software behtar karne ka matlab hota hai ke developer code padhe aur us mein change kare. Yahan aap ye step skip karte hain. Aap masla apne aam alfaz mein batate hain, aur agent padhna aur change karna khud karta hai.

Skill sirf likhi hui hidayat ka ek set hai jise aapka agent follow karta hai. Is liye kisi skill ko behtar karna coding ka kaam nahi, ek baat cheet hai. Aap kahte hain “ye hamesha fail hota hai jab koi ise Robinhood link deta hai”, aur wo ja kar usay theek kar deta hai.

Ye kyun karna chahiye: aap jo skill behtar karte hain wo behtar hi rehti hai. Agli bar wahi kaam aaye to agent ko jawab pehle se pata hota hai.
Koi alag bill nahi. Ye usi subscription par chalta hai jo aapne pehle se set up ki hui hai. Lambe kaam baat cheet se zyada usage lete hain, is liye pehle kuch kaam ke baad apna usage page dekhein, phir iski fikar chhor dein.

02Chaar step ka loop

STEP 1

Jo chahte hain wo batayein

Aasan alfaz mein, Discord mein. Agar aap kisi insaan ko bata sakte hain, to yahan bhi bata sakte hain.

STEP 2

Ise kaam karne dein

Ye skill padhta hai, samajhta hai ke kya change karna hai, aur change kar deta hai. Ise kahein ke ek line mein bataye ke kya kiya.

STEP 3

Ise sabit karwayein

Kahein “test karke mujhe output dikhao”. Ye wo step hai jo log skip kar dete hain, aur asal mein yahi sab se zyada ahem hai.

STEP 4

Jab tak theek na ho, dohrayein

Agar theek nahi hua, to batayein ke ab bhi kya masla hai. Do ya teen round aam baat hai.

“Done” koi result nahi hota. Agent aapko bata sakta hai ke kaam mukammal ho gaya, halanke wo chalta nahi. Hamesha asal output, asal error, ya asal link maangein. Agar wo aapko dikha nahi sakta, to kaam mukammal nahi hua.

04Jab in mein se koi ek toot jaye

Yeh sab se aam cheez hai jo aap karenge, aur yeh bilkul normal hai. Kuch error deta hai, aap error wapas paste karte hain, aur wo ise theek kar deta hai.

@yourbot yeh kaam nahi kiya. is ne yeh kaha: <paste the whole error>

@yourbot pichhli baar ki tarah hi, lekin is wallet address ke saath: <address>

@yourbot pata karein ke yeh baar baar kyun fail hota hai, sirf dobara try karne ke bajaye

@yourbot wapas jaise pehle tha waisa kar dein, is change ne cheez kharab kar di

@yourbot aap ne kaha yeh kaam karta hai lekin nahi kiya. dobara aisa kehne se pehle mujhe saboot dikhayein ke yeh kaam karta hai
Poora error paste karein, summary nahi. Yeh bad-soorat text ki deewar hi asal mein wahi cheez hai jiski zaroorat hai. Ise trim karna hi fixes ko ek ke bajaye chaar koshishon mein badal deta hai.
Agar yeh zyada kharab ho jaye, rollback maangein. “Wapas jaise pehle tha waisa kar dein” ek jaiz aur kaam ka prompt hai. Bade changes se pehle ise ek copy save karne ke liye kahein taake yeh hamesha mumkin ho.

05Ise kuch naya sikhayein

31 skills sirf shuruaat hai. Asal value apne skills add karne mein hai, un kaamon ke liye jo aap baar baar karte hain.

@yourbot dekhein ke main kharidne se pehle mint kaise check karta hoon, phir ek skill likhein taake agli baar aap yeh mere liye kar sakein

@yourbot ek skill banayein un collections ko dhoondne ke liye jahan floor abhi gira hai

@yourbot jab bhi main ek tweet paste karoon, aap check karein ke yeh mint hai ya nahi, iski qeemat kya hai, aur yeh asli hai ya nahi. ise ek skill bana dein

@yourbot ek skill banayein jo mere sab wallets check kare aur batayein koi cheez jis par mujhe dekhna chahiye

@yourbot kuch aisa banayein jo do collections ka side by side muqabla kare aur batayein kis mein behtar chances hain
Har repeat hone wali cheez ko skill bana dein. Agar aap ne ek hi baat do baar samjhai hai, to wo ek skill hai. Aap ko teesri baar kabhi samjhana nahi parega.

06Ek chhoti si poori cheez banwayein

Wahi idea, bara roop. Aap ise ek kaam karta page banwa kar online dalwa sakte hain, aur isi ke liye setup guide ka Vercel wala hissa hai.

@yourbot mere liye ek page banayein jis mein wo har collection ho jo mere paas hai, images aur rarity rank ke saath

@yourbot un collections ka ek simple dashboard banayein jinhein main dekh raha hoon aur ise Vercel par dal dein

@yourbot ek page banayein jahan main collection link paste karoon aur wo sab kuch rank kare aur pictures dikhaye

@yourbot ise Vercel par dal dein aur mujhe link dein jab yeh waqai live ho
Live link maangein, “ho gaya” nahi. Agar wo kehta hai ke site up hai, to URL maangein aur khud kholein. Yeh ek aadat is tarah ki ghaltiyon ka zyada tar hissa pakad leti hai.

08Mushkil se door rehna

  • Private key kabhi paste na karein agent ke saath chat mein, ya kisi aur jagah. Agar aap ne kabhi kiya hai, to us wallet ko jala hua samjhein aur us mein jo kuch hai wo nikal lein.
  • Bade changes se pehle plan maangein. “Pehle plan dikhayein” aap ke das second leta hai aur ek badi museebat bacha leta hai.
  • Ek waqt mein ek change. Teen improvements ek saath ka matlab hai aap nahi bata sakte kis ne ise torha.
  • Apne paise ko ek “nahi” ke peeche rakhein. “mere poochhe baghair kuch kharch na karein” kahein aur wo nahi karega.
  • Gehrai mein jaane se pehle backup lein. Pehle apne skills ki copy save karne ke liye kahein: “mere skills folder ki copy kisi mehfooz jagah rakh dein”.
  • Agar wo kamyabi ka dawa kare aur aap use dekh nahi sakte, to wo asli nahi hai. Dobara saboot maangein.
