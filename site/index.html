What it covers

rarity

Rank a collection

OpenRarity information content, validated rank for rank against OpenSea on a 5000-token collection. Includes reveal detection, full-supply sweeps, and a holdings dashboard.

mint

Fire a public mint

SeaDrop kit for many wallets at once: recon, fresh wallets, funding check, eth_call pre-flight, pre-signed blast, then confirmation that the token landed.

snipe

Buy rare at the floor

Seaport buy path through OpenSea fulfillment data, plus a read-only diagnostic that prints the actual revert reason so you are not guessing.

proof-of-work

Mine the nonce

CPU, CUDA, and Metal miners for FAB4200 and Hashcats style preimages, with self-checks that catch a broken hash before you rent a GPU.

wallets

Reconstruct P&L

FIFO matching of every acquisition and disposition across Ethereum and Robinhood Chain. Mints are separated from buys, and gas is counted as a cost.

forensics

Audit a launch

Wash-ring tells, holder concentration, contract-stack discovery, developer-wallet link tests, and dust-token scam assessment, all without an API key.

  • Keyless where it can be. Public RPCs and marketplace pages carry the on-chain facts. A paid key only unlocks the trading paths.
  • Simulation before broadcast. Every spending script runs eth_call first. It is what stopped a batch of 49 reverts.
  • Caps in the code. Per-buy, per-day, and reserve limits are constants, and live execution ships disabled behind an explicit flag.
  • Corrections kept in. A rarity formula that was wrong, a mint price that was misread, and a sniper path that reverted every time are all still in the skills, because the correction is what makes them useful.
Read this before you spend anything. The toolkit moves real assets on public chains. Nothing here is financial advice, and no strategy in it is profitable by construction. Simulate first, set caps, and approve deliberately.
