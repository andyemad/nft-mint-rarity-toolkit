What you can build

rarity

Rank any collection exactly

OpenRarity information content — Σ −log₂(count/total) — validated rank-for-rank against OpenSea. Reveal detection, full-supply sweeps, holdings dashboards.

mint

Fire a public mint at T-0

SeaDrop multi-wallet kit: recon, fresh wallets, funding poll, eth_call pre-flight, pre-signed blast, then verify the token actually landed.

snipe

Buy rare at the floor

Seaport buy path via OpenSea fulfillment data, plus a read-only diagnostic that shows the real revert reason instead of guessing.

proof-of-work

Mine the nonce

CPU (OpenMP), CUDA and Metal miners for FAB4200- and Hashcats-style preimages, with self-checks that catch a broken hash before you rent a GPU.

wallets

Reconstruct real P&L

FIFO matching of every acquisition and disposition across Ethereum and Robinhood Chain — mints separated from buys, gas reported as a cost.

forensics

Audit a minter or a claim

Wash-ring tells, holder concentration, contract-stack discovery, dev-wallet link tests and dust-token scam assessment — all without an API key.

required API keys
  • Keyless by default. Public RPCs and marketplace pages for on-chain facts; a paid key only unlocks the trading paths.
  • eth_call before every broadcast. Simulation is a requirement, not a nicety — it is what stops a 49-revert batch.
  • Bounded authority. Per-buy, per-day and reserve caps are constants in the scripts, and live execution ships disabled behind an explicit flag.
  • Corrections kept in. A wrong rarity formula, a mis-read mint price and a sniper path that reverted every time are all documented — the correction is the useful part.
Read before spending. This toolkit moves real assets on public chains. Nothing here is financial advice and no strategy in it is profitable by construction. Simulate, cap, and approve deliberately.
