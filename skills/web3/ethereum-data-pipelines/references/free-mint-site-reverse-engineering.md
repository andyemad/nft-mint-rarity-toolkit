# Reverse-Engineering an Unknown (Free) Mint Site to determine if/when it can be minted

Verified 2026-08-18 on FABLINGS (fablings.fun, Robinhood chain). Use this when the user
shares a minting-game/collection site that is NOT a standard public SeaDrop mint and asks
"can you mint this for free?" — you must read its real on-chain mechanics rather than trust
the landing copy, and you must be honest about drip gates before promising a mint.

## 1. Pull the site's JS config (the contract/chain truth lives in code, not copy)
The HTML `<title>`/`og:` gives the name; the real chain, contracts, prices and caps live in
shipped JS. Grab bundles in order of likelihood:
- `src/config.js` (often a GENERATED file: "GENERATED by ops/gen-config.mjs from params.json")
- `src/statics.js`, `src/app.js`, `src/gen/abi.js`, `src/errors.js`
`curl -A "Mozilla/5.0 ..."`. Reader pattern that worked:
```bash
for p in config.js src/config.js ./config.js; do
  code=$(curl -sL -A "$UA" -o /tmp/cfg.js -w "%{http_code}" "https://SITE/$p")
  [ "$code" = 200 ] && break
done
python3 - <<'PY'
import re
s=open('/tmp/cfg.js').read()
print(re.findall(r'"chainId":\s*"?(\d+)', s))          # 4663 = Robinhood
print(re.findall(r'"items":\s*"?(0x[0-9a-fA-F]{40})', s))   # the NFT/mint contract
print(re.findall(r'"freePerWallet":\s*"?(\d+)', s))
print(re.findall(r'"mintInterval":\s*"?(\d+)', s))     # global free-drip cooldown (seconds)
PY
```
Key config fields: `chainId`, `addresses.items` (the contract you call `mintFree()` on),
`addresses.lens` (read helper), `params.freePerWallet`, `params.mintInterval`,
`params.skipPrice` (the PAID lane — only if free is capped out).

## 2. Read the ABI/flow to find the actual free-mint function
`app.js` wiring shows which function is "free": it calls `functionName: "mintFree", args: [],
value: undefined` (value undefined = genuinely free, gas only) vs `mintSkip` which passes
`value: skipPrice * qty` (paid). Confirm `mintFree()` takes NO value before ever calling it.

## 3. Check per-wallet usage ON-CHAIN (do not trust the site's counter)
`freeMinted(address)` returns how many free hatches a wallet already used. On RH RPC
(`eth_call`, urllib needs `User-Agent: Mozilla/5.0`):
```
data = selector('freeMinted(address)') + '0000..' + wallet[2:].lower()
word0 of return = used count. freeLeft = freePerWallet - used.
```

## 4. Simulate before promising (gate reality check)
`eth_call` the exact mint tx from the target wallet: `{from: wallet, to: items, data: mintFree()}`.
- `result` key present = would currently succeed (mint open + cooldown elapsed + cap not hit).
- `execution reverted` (+ data selector like `0x5273678a`) = currently blocked.
  MUST decode why before saying "yes, free mint works".

## 5. Decode the revert selector — hash `Error(Name())`, don't guess
The first 4 bytes of revert data are keccak256(`Error(<Name>())`)[:8]. Read `src/errors.js`
for the site's `Name: "Human sentence"` map, then:
```python
from Crypto.Hash import keccak
def esel(name):
    k=keccak.new(digest_bits=256); k.update(f'Error({name}())'.encode()); return k.hexdigest()[:8]
TARGET='5273678a'
for name in ['MintNotOpen','FreeWalletCapReached','IntervalAboveCap','ElementSoldOut','ReserveClosed']:
    print(name, esel(name), '<== MATCH' if esel(name)==TARGET else '')
```
**Pitfall:** a revert selector that matches NONE of the site's listed error names does NOT
mean "free mint is open" — it means an unlisted condition is blocking (e.g. a drip window is
currently taken by another wallet on a GLOBAL 1-per-N-seconds line, or a custom/unknown
revert). Treat unknown-selector revert as "cannot confirm it mints now"; do NOT broadcast.

## 6. Detail the gate honestly before proposing
Drip-gated free mints have these realities (FABLINGS-specific, illustrative):
- Free mint is genuinely **zero-price** but **gas-only** cost (~0.02 gwei on RH ≈ $0.01).
- **Per-wallet cap** (e.g. 10) AND a **global cooldown** (1 free hatch per `mintInterval`
  seconds) → it is a LIVE RACE against other wallets; a slot may not be claimable at the
  moment you simulate.
- The **paid lane** (`mintSkip`, e.g. 0.0005 ETH) has no wallet cap but costs real money.
Present the user a real choice: fire on the bot wallet (approve the tx), point a personal
wallet that holds gas, or skip.

## Diagnostic recap that worked
config.js → (chainId 4663, items `0xa18581…b384`, freePerWallet 10, mintInterval 10)
→ app.js (`mintFree` no-value, `mintSkip` paid) → on-chain `freeMinted(bot)=1` → simulate
`mintFree` reverted 0x5273678a → selector hash matched none of MintNotOpen/
FreeWalletCapReached/etc → verdict: "free mint is real and capped, but a slot isn't
claimable right now; won't broadcast without approval."

## 7. Executing the claim — the drip watcher pattern (verified 2026-08-18)
Once a drip-gated free mint is confirmed real, claim paid-free hatches with a watcher that
polls the SIMULATE probe and broadcasts the instant a slot opens:

```python
def simulate(addr):  # eth_call, no broadcast, no gas cost
    data = sel("mintFree()")
    r = rpc("eth_call", [{"from": addr, "to": ITEMS, "data": data}, "latest"])
    if "result" in r: return True, None       # slot open -> broadcast now
    err = r.get("error", {}); d = err.get("data", "")
    return False, (d[:10] if d else "?")
# on True: eth_estimateGas, sign ({to} to_checksum_address, raw hex "0x"-prefixed,
# fresh nonce), eth_sendRawTransaction; confirm eth_getTransactionReceipt status=1
# AND freeMinted ticking up.
```
Cron shape: minute-interval no-agent cron that `--once`-checks and self-exits; broadcast
only when a slot is open, silent otherwise; `deliver local` (don't spam a channel with
"not open" lines). Free mint =`value=0` (gas ~$0.01 at RH 0.02 gwei) but still a real
on-chain action that mints an NFT into a wallet → same approval gate as any spend.

## 8. Safety discipline — the expensive lesson this session
- **Sanity-check a broadcast-capable watcher in NOOP/simulate mode, never with its live flag.**
  A "quick wrapper sanity run" of a script that already has `--fire` BROADCASTS a real tx
  the instant the drip slot happens to be open (this is exactly what happened on FABLINGS —
  a free mint fired before the user approved). Keep `--fire` behind approval + explicit
  intent, not in the default wrapper; test the `--noop`/`--once` path.
- Real free-mint claiming needs approval even at $0 ETH (gas + an NFT lands in a wallet):
  propose slate (recipient wallet, max = gas-only for N remaining free mints, cancel=instant),
  get approval, consume, arm.
- Data races on the real drip: the global window means other wallets grab slots; you only
  win by simulating tight and broadcasting fast. Set expectations honestly — it's a race.

## Environment note
`timeout` is NOT on macOS by default. Verify a self-limiting script with its own `--once`/exit
flag instead of wrapping in a GNU-coreutils `timeout` (which just errors `command not found`).
