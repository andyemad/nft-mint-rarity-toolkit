# RPC failover and OpenSea mint-link details

## Robinhood RPC capability gate

Wallet Radar scans every NFT contract for watched-wallet topic positions, so a
candidate RPC must support **addressless** `eth_getLogs`; proving only
`eth_blockNumber` or `eth_chainId` is not enough.

Validated production shape (2026-09-07):

- Primary: `https://rpc.ordofi.network`
- Secondary: `https://rpc.mainnet.chain.robinhood.com`
- Expected chain ID: `0x1237` (4663)
- Implementation: `ChainConfig.rpc_fallback_urls` plus
  `WalletRadarService.rpc()`, which tries all unique endpoints per retry round.
- Never put a restricted provider into production merely because head reads work.
  Probe the same addressless Transfer-topic filters generated by `_log_filters()`.

Regression coverage belongs in `tests/unit/test_wallet_radar.py`:

1. Registry pins the primary and secondary endpoint order.
2. A failing primary is followed by the secondary before another retry round.
3. Existing bounded-retry and sanitized-error behavior remains intact.

Activation verification:

1. Run the focused Wallet Radar tests, compile checks, and lint.
2. Restart only `com.hermes.wallet-radar`, never the Hermes gateway.
3. Read SQLite cursors twice after restart; both Ethereum and Robinhood must move.
4. Compare Robinhood cursor with a fresh RPC head if it stalls.
5. Confirm the RPC error-log line count does not grow during the observation.
6. Inspect outbox status separately; cursor health does not prove delivery.

## NFT mint links

`format_discord_message()` follows this order for EVM mint alerts:

1. Resolved token-level collection slug -> OpenSea collection URL.
2. No slug but token ID known -> exact OpenSea item URL using the OpenSea chain
   path (`robinhood-chain` or `ethereum`).
3. Transaction fallback only when an OpenSea item cannot be constructed.

Keep token-level collection resolution keyed by `(chain, contract, token_id)` so
shared ERC-721 contracts cannot be mislabeled. The item fallback is intentionally
safe when OpenSea has not indexed the collection slug at alert time.
