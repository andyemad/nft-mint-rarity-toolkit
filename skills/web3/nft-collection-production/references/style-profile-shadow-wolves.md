Session 2026-08-22: the user began a new "learn from examples → design my own
collection" engagement by submitting Shadow Wolves
(https://opensea.io/collection/shadow-wolves, CA 0x858df9f84c73e01c55a2dfb95825401242a65d64,
6,250 supply, verified, Cool Cats' mid-tier "Super Cool" membership PFP).
This file records (1) how to fetch reference samples for study, and (2) the
extracted style DNA to match when he commissions his own art.

## Fetching reference samples for style study (verified workflow)

1. `GET api.opensea.io/api/v2/collections/<slug>` works KEYLESS — gives
   description, contract address, chain, banner. (The per-NFT endpoint
   `/api/v2/chain/<chain>/contract/<ca>/nfts/<id>` does NOT — it 401s without
   an API key.)
2. Get tokenURI on-chain: selector `0xc87b56dd` + uint256 pad, via a public
   Ethereum RPC. Public RPCs rate-limit/flake heavily (verified 2026-08-22:
   llamarpc/cloudflare/flashbots/mevblocker/drpc/blastapi/ankr all 403'd or
   needed auth; `https://eth.rpc.blxrbdn.com` worked reliably for eth_call).
   Treat any single free RPC as unreliable — rotate and retry rather than
   concluding failure.
3. Decode tokenURI defensively: some contracts return ABI-encoded strings,
   others base+id patterns. Robust decode: `re.search(rb'https?[^\\x00]+',
   bytes.fromhex(res[2:]))` then strip NULs — beats manual offset math, which
   broke twice (truncated head / trailing garbage) before this pattern.
4. Metadata location varies per collection: plain S3 JSON without `.json`
   suffix (Cool Cats ecosystem), Arweave per-token URLs (HOWLERZ), or IPFS
   CID + `/{id}` (Pudgy Penguins). Follow the URI; don't guess.
5. IPFS gateways are flaky from Python urllib (pinata 429s under repeat calls;
   nftstorage.link failed for Pudgy CIDs). `curl -sL --max-time 30` against
   `https://ipfs.io/ipfs/<path>` worked when every Python gateway attempt
   failed. Fall back to subprocess curl before declaring a CID unreachable.
6. Download `image` to local PNGs, then vision_analyze a spread (sample
   across token-id range AND trait variety: common + rare tiers). Batch two
   vision_analyze calls per turn where independent.

## Shadow Wolves style DNA (from vision analysis of 7 samples)

- Flat vector PFP, thick uniform black outlines, rounded joins — sticker feel.
- Solid black fur mass; fur texture IMPLIED by jagged/spiky silhouette edges,
  never drawn strands or strokes.
- Minimalist eyes: solid yellow circles OR yellow slitted pupils, no
  highlights/sclera. Expression = grumpy/unimpressed line mouth. Asymmetric
  eye variants exist (X-eye + circle = KO'd look).
- Strict ~4–6 color palette per token; ONE loud flat background color each
  (orange, salmon, lime, grey) — bg varies per token, character stays black.
- Cel-shade accents only: single lighter block per surface (diagonal white
  glint stripe on goggle lenses, white shine dot on poison apple).
- Bust framing, head fills frame, reads at avatar size.
- Trait z-order: bg → body/head+ears → face → forehead accessory → collar →
  clothing/jacket. Collar (fluffy fur lines / lapels) frames the face.
- Personality comes from ACCESSORIES (gas masks, goggles+helmet, poison
  apple, leather jacket, flowers/bows), not face variation — faces stay
  within one grumpy mood family.
- Trait taxonomy observed: Hat, Face, Shirt, Tier (Shadow 1 / Sinister 2 /
  Primal 2 …). Tier names double as rarity branding.

## HOWLERZ style DNA (from vision analysis of 6 samples, 2026-08-22)

Source: https://opensea.io/collection/howlerz, CA 0x40cf6a63c35b6886421988871f6b74cc86309940,
Ethereum, 4,994 supply, CC0 "drawn by hand, generated by code". Metadata lives
on Arweave; tokenURI is a per-token URL (base + /<pseudo-random id>), so you
MUST read tokenURI per token — do not assume a shared base + token number.

- Hand-drawn flat vector with deliberate imperfection: marker-textured X eyes,
  scribble details — NOT sterile perfect vector. This is the anti-"MS Paint"
  differentiator: the looseness is authored, not sloppy.
- Same thick black outlines + strictly flat fills, zero grain.
- Wilder palette than Shadow Wolves: neon yellow, rainbow bands, lavender fur,
  periwinkle blue — still limited per-piece.
- Backgrounds go beyond solid color: rainbow sunburst bands, soft purple
  swirls, wavy patterns. Patterned bg is a trait axis of its own.
- EYES are the signature/rarity system: XX (KO'd), Beatnik glasses with
  lightning bolts, shutter shades with rainbow slats, Cubist white diamonds.
- Character TYPES vary structurally (skeleton wolf, horned dragon-wolf,
  puffer-suit bodies) — not one base body recolored.
- Personality = absurd juxtaposition: skeleton + tactical vest + propeller
  beanie; angel wings + leather jacket + beatnik glasses.
- Sharp yellow teeth, lolling tongues, manic grins — energy/mischief over the
  "bored" face.

## Pudgy Penguins style DNA (from vision analysis of 5 samples, 2026-08-22)

Source: https://opensea.io/collection/pudgypenguins, CA
0xbd3531da5cf5857e7cfaa92426877b022e612cf8, Ethereum, 8,888 supply. Metadata
on IPFS (`ipfs://bafybei…/{id}`); ipfs.io worked via curl when Python urllib
gateways 429'd.

The CUTE lane:
- Same discipline: thick black outlines, flat fills, no gradients.
- Body built from overlapping circles/ovals — extreme roundness IS the brand
  ("pudgy" silhouette). Roundness is a shape-language choice any collection
  can adopt deliberately.
- Big glossy almond eyes with white catchlights = instant charm; props use
  simple dot eyes for contrast.
- Warm pastel palette (peach, pink, cream, baby blue) vs dark/neon lanes.
- Headwear is oversized and DOMINANT — the polar-bear helmet swallows the
  whole head. Hats as hero element, not stamps.
- Friendly/neutral expression family; face shading is minimal color-blocking.

## Cross-reference synthesis: the shared collectible-grade bar

Three top collections agree on:
1. Thick black outlines + flat color blocking; zero gradient mush.
2. Silhouette-first design that reads instantly at avatar size.
3. Eyes carry personality AND rarity weight (each collection solves this
   differently: deadpan slits / signature eye systems / glossy catchlights).
4. Accessories tell a story or create juxtaposition, never clip-art stamps.
5. Limited palette per token against a loud/contrasting background.
6. Bust framing; head fills frame.

Lane matrix for choosing direction:

| | Shadow Wolves | HOWLERZ | Pudgy Penguins |
|---|---|---|---|
| Mood | Grumpy streetwear | Chaotic punk | Cute wholesome |
| Eyes | Yellow slits, deadpan | Signature systems | Glossy catchlight orbs |
| Palette | Dark + loud solid bg | Neon + patterned bg | Pastel + soft bg |
| Silhouette | Spiky fur tufts | Structural variety | Extreme roundness |
